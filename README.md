# 墨阳阅读器 · Moyang Reader

一个以本地文件为基础的阅读、写作与个人 AI 工作台。阅读 Markdown、TXT、Word 和 PDF，整理自己的知识、长期记忆与技能，也可以让外部 AI Agent 通过 MCP 使用这些积累。

界面采用暖白与墨绿，支持深色模式、舒适 / 紧凑密度、文档标签和双窗格。阅读空间、AI 空间与可选聊天各有入口，切换时保留正在处理的内容。

**[下载 Windows 版](https://github.com/MY-moss/moyang_Reader/releases/latest) · [使用指南](docs/USER-GUIDE.md) · [AI 空间](docs/AI-USER-GUIDE.md) · [问题反馈](https://github.com/MY-moss/moyang_Reader/issues)**

## 用它解决什么问题

- **资料散在很多文件夹里**：把现有文件夹加入阅读库，在同一处阅读、搜索、摘录与整理，继续使用原来的文件。
- **边看资料边做笔记**：双窗格并排打开原文和笔记，用链接连接相关内容，导出成文档分享。
- **每次换 AI 都要重新解释背景**：把明确偏好、项目决定与经验存入长期记忆，让接入的 Agent 按项目召回。
- **希望 AI 复用自己的资料和方法**：知识库存资料，技能库存做事步骤；让 Agent 按需读取，而不是每次粘贴整套内容。
- **想围绕正在读的文档交流**：使用自己的 API，在应用里提问，明确选择发给 AI 的文档与资料。

你可以只用它读文档和写笔记，再按需要开启 AI 与扩展。

## 下载与开始使用

当前发布版本为 **0.14.0**，维护平台为 **Windows x64**。

1. 在 [GitHub Releases](https://github.com/MY-moss/moyang_Reader/releases/latest) 下载 `moyang-reader-<版本>-windows-x64.zip`。
2. 完整解压到一个可写入的本机文件夹，打开 `Moyang Reader Next.exe`。保留同目录的 `moyang-ai-mcp.exe`。
3. 在阅读空间打开文件，或添加整个文件夹作为阅读库。原文留在原来的位置，不复制进私有文档库。
4. 想让 AI 使用资料时，切到 AI 空间，明确导入需要的内容；想聊天时，再到插件市场安装聊天助手。

发布包是便携 ZIP，无需传统安装器。系统需要 WebView2 运行环境；下载校验与问题报告见 [SECURITY.md](SECURITY.md)。

公开下载的轻量包**不包含 Ollama 运行程序和模型**。普通阅读、编辑、关键词检索与自定义 API 聊天可以分别使用；AI 语义检索需要本机 Ollama 与 `qwen3-embedding:0.6b`，模型约 639 MB。准备方式见 [AI 空间指南](docs/AI-USER-GUIDE.md#检索与本地模型)。嵌入模型用于检索，不能作为聊天模型。

### 阅读、编辑与恢复

- 单击文件复用临时标签，双击或开始编辑后保留。双窗格分别保留位置；打开同一文件时共享正文和保存队列。
- Markdown 支持选区格式工具条、`/` 插入菜单、双链补全和源码模式。无法无损往返的结构使用源码编辑；TXT 保持纯文本。
- 停止输入约 1.2 秒后自动保存，中文输入法组词期间暂停；`Ctrl+S` 立即保存。外部修改与本地草稿冲突时，可以比较、合并或另存副本。
- 全文搜索覆盖 Markdown、TXT、DOCX 和文字型 PDF，点击命中片段定位段落或物理页。PDF 支持页码、翻页和缩放。
- 摘录、批注和收藏保留来源；恢复中心提供回收站与历史比较。可导出 HTML、Word、PDF，并按筛选范围批量导出。

DOCX 以转换后的内容阅读，不保证与 Word 的复杂排版完全一致。扫描 PDF 暂无 OCR；PDF 批注采用页级来源，暂不提供页内高亮。

### 知识、长期记忆与技能

AI 空间与日常笔记独立，只有明确导入的资料进入 AI 库，MCP 不自动遍历普通阅读库。

- **知识**：导入 MD、TXT、DOCX、文字型 PDF 或网页正文，保存独立快照和来源。原资料变化后，检查差异再更新。
- **长期记忆**：保存有依据的偏好、事实、决定和经验，支持全局 / 项目范围、有效期、历史、撤回与冲突处理。明确更正可替代旧规则，仍保留历史。
- **技能**：导入 `SKILL.md`、技能目录或 ZIP，管理正文、参考资料和资源，比较版本并恢复。资源按需读取，应用不会执行技能中的脚本。
- **检索**：先返回关键词结果，再补充本地语义结果；提供多个来源片段和位置。模型服务不可用时保留关键词检索。

例如，知识库可以放项目资料和技术文档；长期记忆可以保存“这个项目使用两个空格缩进”和已经确定的方案；技能库可以保存代码审查、资料整理等操作流程。

使用时先选择全局或具体项目，避免把一个项目的规则带到另一个项目。需要修改时可以直接编辑，也可以比较修订并恢复旧内容。这些积累为 Agent 提供上下文和方法，不会训练或修改外部模型权重。详见 [AI 使用指南](docs/AI-USER-GUIDE.md)。

### 让外部 Agent 使用 AI 库

进入 **AI 空间 → 接入与备份**，为 Codex 或 Claude Code 配置连接；其他客户端使用页面生成的通用 MCP 配置。客户端启动独立的 `moyang-ai-mcp.exe`，无需一直打开阅读器。

连接后，可以从一次小任务开始：

1. 重新连接或重启客户端；按客户端提示授权 MCP，并检查自动沉淀钩子的信任状态。
2. 告诉 Agent：“请记住，这个项目的文档使用简洁中文，并注明来源。”
3. 在墨阳的近期活动中查看保存内容与原因，再开一次任务，让 Agent 回忆这个项目的文档要求。
4. 要更正偏好时直接明确说明；在墨阳中可以查看变化、处理冲突或撤回不合适的记录。

自动沉淀会挑选有长期价值的信息，没有新结论的任务无需新增记录。它是否自动触发取决于客户端的生命周期支持与授权；通用 MCP 客户端也可以通过工具手动召回和保存。详细配置与工具说明见 [MCP 指南](docs/MCP-GUIDE.md)。

### 按需启用聊天与扩展

1. 在插件市场安装「书房聊天」「共读伙伴」或「双语阅读」，点击「开始聊天」。
2. 在「API 服务」添加服务名称、协议、基础地址、密钥与默认模型。支持 OpenAI 兼容 Chat Completions 和 Anthropic Messages，也可使用兼容的本机服务。
3. 获取模型列表，或手动填写模型 ID；有多个配置时，可以在对话中切换服务与模型。
4. 打开要讨论的文档，按需选择「附加当前文档」或「AI 库召回」，检查内容后发送问题。
5. 回答可以停止、重试、导出为 Markdown；有价值的内容可确认后存入 AI 库。

聊天默认不读取普通笔记，AI 库召回也默认关闭；需要时显式附加文档或开启项目范围召回，发送前可查看来源。回答经确认后可以存入知识或长期记忆。停用助手保留历史与服务配置。

阅读插件、主题、技能、MCP 连接和助手预设均从插件市场管理，支持本地导入、安装、停用、更新与回退。详见 [聊天指南](docs/CHAT-EXTENSIONS.md) 和 [扩展指南](docs/EXTENSIONS.md)。

0.14 精选扩展共 15 项。新增待办提取、链接清单、表格导出和文档体检，可从详情直接运行，点击结果定位原文，或保存清单及 CSV；这些阅读工具全部离线运行。另有论证审阅、复习教练两个聊天助手，以及来源核对技能，按需安装。

## 数据、备份与更新

| 数据            | 保存方式                                                     |
| --------------- | ------------------------------------------------------------ |
| 普通文档        | 原来的本机文件夹，保留原文件格式                             |
| AI 资料         | 独立 SQLite 数据库、资源、修订和快照；在 AI 空间导出完整备份 |
| 聊天与 API 配置 | 独立聊天数据库；完整恢复需备份聊天目录，AI 库备份不包含它    |
| 草稿与界面状态  | 本机应用数据；关闭、恢复与迁移时一并处理                     |

基础阅读与本地资料管理可离线使用。使用远程聊天服务、网页导入、远程扩展目录或在线更新时会访问对应网络服务；只有明确附加或召回的资料进入聊天请求。API 密钥保存在本机配置中，不进入聊天导出或助手包；本机配置库不是加密保险箱。

在 **设置 → 存储位置** 查看实际路径与占用，将应用资料迁到其他本机磁盘，也可选择迁移本应用的便携模型。普通阅读库不随之搬动，Windows 目录链接保持已有 MCP 路径可用。迁移步骤与失败恢复见 [存储位置指南](docs/STORAGE-LOCATIONS.md)。

在 **设置 → 应用更新** 检查新版本，可选择启动检查和自动下载。更新包经过签名校验，先保存再切换程序，保留上一版本用于回退；不会重复下载模型。详见 [更新与回退](docs/ONLINE-UPDATES.md) 和 [迁移恢复手册](docs/MIGRATION.md)。

## 常见问题

**一定要配置 AI 才能使用吗？** 不需要。阅读、编辑、全文关键词搜索、摘录和文件管理可以独立使用。

**能离线使用吗？** 本地阅读与资料管理可以。本机嵌入模型准备好后，语义检索也在本机处理。聊天是否需要联网取决于你选择的服务。

**笔记会自动发给 AI 吗？** 不会。阅读库不会自动进入 AI 库；聊天也需要显式附加文档或开启召回。使用远程 API 时，所选上下文会发送给该服务。

**知识库和长期记忆有什么区别？** 知识库保存“供查阅的资料”，记忆库保存“以后应当记住的事实与约定”，技能库保存“如何完成某类任务”。三者可以一起提供给 Agent。

**本地模型需要下载几次？** 公开轻量包不附带模型，需要另行准备。在线更新复用已有模型，不随每次更新重复下载。

**所有 PDF 都能搜索吗？** 需要有文字层；扫描件暂不提供 OCR。DOCX 以转换后的内容阅读，复杂排版可能与 Word 不同。

## 想自己运行或修改？

前端使用 React、TypeScript、Vite，桌面使用 Tauri 2 与 Rust，AI 数据使用 SQLite。准备 Node.js 22、npm；桌面编译还需要 Rust MSVC、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。

```powershell
git clone https://github.com/MY-moss/moyang_Reader.git
cd moyang_Reader
npm ci
npm run desktop
```

只预览界面用 `npm run dev`，默认地址为 `http://127.0.0.1:1420`；浏览器预览不具备完整桌面文件读写能力。`npm run build` 构建前端，`npm run package` 生成桌面便携包。有本机成功打包的程序后，可用 `npm start` 或双击 `启动阅读器.cmd` 打开。首次原生编译需要下载依赖，详细环境与命令见 [开发指南](docs/DEVELOPMENT.md)。
