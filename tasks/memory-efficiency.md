## 每项验证

1. 为已复现的范围与活动问题建立回归；覆盖导入未确认时重启恢复、确认后自动保存与当前项目隔离。
2. 验证短记忆无需额外读取、长文连续读取无遗漏、批量预算、未变化响应、更正 / 归档 / 上下文重置不漏证据、未知 patch 字段拒绝且资源不丢失。
3. 正常小任务验证跨进程抢占、超额停发、失败和缺 usage 结算、中断续做、不同数字 / 版本 / 否定 / 项目不误合并、合并后新修改不被撤回覆盖。
4. 旧库快照 / 迁移 / 历史资源字节 / 损坏备份拒绝 / 恢复可用；关闭等待草稿写入；聊天来源可检查，历史附件不机械重复。
5. 目录含中文 / 空格、空间不足 / 文件占用 / 中途退出 / 原路径兼容；API 无密钥泄漏、取消贯穿请求、切换模型不混维度，离线时保留关键词检索。用户决定是否下载，不自动下载所有档位。
6. 架构、类型、单元、Rust、浏览器和桌面顺序验证；记录工具目录、请求响应字数和真实 API usage，不做人工堆量压测，不把字符当计费 token。

## 边界

保留 React / Tauri / Rust / SQLite、原始阅读文件和启动方式。普通笔记不自动进入 AI 库。新增模型是可选嵌入模型，不增加重排 / 总结本地模型链。API 整理首次由用户选择模型及每日额度。系统临时文件和第三方 Ollama 实例不能谎报为本应用可控目录，必须展示实际路径及可操作边界。
