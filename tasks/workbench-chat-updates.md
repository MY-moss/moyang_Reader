# 工作台、聊天扩展与在线更新（2026-10-16）

本轮用户要求继续简化页面与交互、统一现代图标，补上可用的自动更新，并将自定义 API、多服务/模型切换及应用内聊天做成可选插件。普通笔记、AI 库和聊天数据分别保存。

## 实施与验收

补充确认：AI 相关存储必须可自由选择其他磁盘，避免 C 盘持续增长。本轮增加独立存储页、完整目录迁移、实际占用、模型选项、MCP 原路径兼容、复制校验与失败恢复；不直接搬动正在使用的个人资料。

- [x] 研究 Notion / Obsidian 的导航、面板和插件管理，记录具体采用方式；保留暖白墨绿，不重做成企业仪表盘。
- [x] 简化工作台：折叠内容分组、收拢低频管理项、清晰的当前页面与返回入口、统一图标；阅读/AI/市场/聊天切换保持会话。
- [x] 可选聊天扩展：安装/启用才显示入口，停用保留会话；聊天记录本地保存，支持流式回答、停止、重试、删除、导出。
- [x] API 配置：多配置命名、OpenAI 兼容与 Anthropic 协议、模型列表和手动填写、默认服务及会话内切换；密钥不进入聊天导出和日志。
- [x] AI 增强：可选项目范围召回、显示实际发送的来源，显式附加当前文档；回答可以保存到知识或记忆库，避免把聊天猜测自动当成事实。
- [x] 插件能力：聊天助手预设可导入/导出，精选实用扩展及主题；安装后可直接打开对应功能，依赖和停用影响明确。
- [x] 在线更新：新项目独立签名发布源、启动检查、手动检查、下载进度、失败重试；下载安装分开，安装前完成草稿和设置保存。便携更新包含程序与 MCP，不重复下载模型。
- [x] 对应单元/原生/浏览器及真实桌面验证；在隔离数据验证 API 流、取消、故障恢复及更新包签名/版本/恢复路径。
- [ ] 更新设计、接口、用户与发布文档，生成当前可用包，检查后同步 GitHub 并归档过期产物。

## 页面与数据边界

侧栏顶部只保留身份/空间切换和搜索、新建；阅读内容分为常用与阅读库，恢复等低频管理收拢。AI 空间区分资料、聊天和管理；API 配置属于聊天插件，MCP 接入、备份和索引属于 AI 管理。插件市场保持“发现 / 已安装 / 更新”，详情按需展示。

聊天采用宿主提供的可选扩展类型与助手预设，插件只声明提示词、建议问题和能力，不获得 API 密钥。远程 API 仅在用户发送消息或测试连接时调用；普通笔记必须显式附加。读取长期记忆沿用现有有界召回，不增加额外模型。

更新采用 Tauri 已有签名下载能力，当前便携版按版本建立新目录后切换入口，保留上一版。签名私钥留在本机发布目录，不进入源码、日志和应用包。旧项目更新源继续独立。

## Direction contract

THESIS：同一个安静的个人工作台，让读文档、积累资料和对话各有一个明确入口。减少重复标题和常驻筛选，把复杂能力放到需要它的位置。

OWN-WORLD：沿用暖白、墨绿和现有浅深色令牌，系统字体、克制边线、统一 Lucide 线性图标。用户在桌面长时间阅读，舒适密度优先，正文和操作不争夺注意力。

STORY：左侧选择空间与内容，中间完成当前任务；资料筛选和管理折叠。聊天是安装后才出现的可选能力，清楚显示使用的 API、模型与资料来源。

FIRST VIEWPORT：固定侧栏与单一页面工具栏；聊天正文居中，编辑框固定在可见区域底部。服务配置独立成页，窄窗按需打开导航。主要操作使用现有墨绿色，避免满屏表单与操作卡片。

FORM：既有 Operate / Read 工作台的局部扩展与整理，不引入新的视觉体系。沿用本次会话既有上下文和用户确认的暖白书房方向，不重新抽选概念。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
