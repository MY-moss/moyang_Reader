# MCP 与 AI 实际使用核验

场景：确认个人库中的记忆可以通过当前 MCP 保存、读取、检索、修改和恢复，并与正式桌面程序保持一致；自动沉淀状态必须有真实客户端证据。

- [x] 对现用个人库创建一致性备份，检查数据库和外键；保留损坏原件。
- [x] 使用独立项目标记的临时记忆与技能验证写入、中文检索、跨项目排除、语义召回、资源读取、版本冲突、修改、恢复和归档。
- [x] 启动正式 0.15.1 桌面程序，读取 MCP 写入，编辑后由新 MCP 进程读回，刷新后内容仍存在。
- [x] 备份导入独立目录，逐条比较正文、资源和全部历史；删除个人库中的临时样本，原有 34 条记录逐条一致。
- [x] 在隔离目录验证两种客户端的重复提示、一次补充、中断恢复、重复沉淀不重复保存；不把模拟事件写成客户端真实回执。
- [x] 修复 Windows 路径写法不同导致连接状态误报，并保留原有钩子定义与成功回执；不同目录保持区分。
- [ ] 正常包和 GitHub 门禁通过后发布修补版，验证实际客户端配置与桌面状态。

真实环境边界：个人应用尚未配置聊天 API；Claude 本地转发服务未运行；新版 Codex 的结束钩子仍缺少真实完成回执。保持待验收，不代替用户信任客户端钩子，不生成虚假回执。
