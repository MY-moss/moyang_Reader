# Moyang Reader 任务入口

此文件仅保留兼容入口，不复制动态待办：

- 当前紧凑任务：运行 `npm run ai:context`
- 批准队列与依赖：[`../docs/ai/plan-v1.json`](../docs/ai/plan-v1.json)
- 唯一动态状态：[`../docs/ai/state.json`](../docs/ai/state.json)
- 人类导航：[`plan.md`](plan.md)
- GitHub Issue 快照：[`../docs/ISSUE-INDEX.md`](../docs/ISSUE-INDEX.md)
- 产品阶段：[`../docs/ROADMAP.md`](../docs/ROADMAP.md)
- 历史完成记录：`CHANGELOG.md`、`docs/handoff/`、GitHub Issue/PR/Release

不要在本文件追加“最近完成”“当前切片”或“下一任务”；它们会与结构化状态漂移。
