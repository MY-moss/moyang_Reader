# 根目录整合与本地清理

目标：当前 0.12 工程成为唯一开发入口；旧源码、独有改动和历史程序可恢复；个人资料不随清理删除。

1. 盘点并归档所有旧工作副本、未提交改动和 Git 历史。验收：归档逐文件校验，Git bundle 验证通过。
2. 将当前工程提升到根目录，更新入口、市场地址、CI、开发与恢复文档。验收：根目录构建和回归通过，无旧子目录依赖。
3. 迁移已有 Agent 的程序路径。验收：其他服务、权限、模型配置和钩子不变，所有权记录同步。
4. 删除已归档副本、旧程序和可再生成缓存，保留当前依赖与本地模型。验收：仅一个 Git 工作目录、一个当前便携包；记录实际释放空间。
5. 增加日常清理预览与应用入口。验收：只清理明确产物，拒绝符号链接，不触碰源码、个人数据或当前发布包。
6. 提交并同步 GitHub。验收：统一质量检查通过，远端主分支包含根目录工程。

外部归档位于项目旁的 `本地阅读工具-归档/2026-10-16/`，不提交仓库。客户端授权和 Claude 模型服务验收仍按用户决定延后。
