# 界面与记忆召回复核

目标：在根目录整合完成后，按已确认方案核对真实操作，优先修复影响日常使用和低成本记忆召回的问题。两个独立界面审查已得到用户授权。

## 步骤与验收

- [x] 两个独立视角检查工作台、AI 空间和插件市场：真实浏览器检查桌面/窄窗口、浅深色、键盘和关键状态，汇总可复现问题。
- [x] 检查置顶记忆的相关片段：先用隔离数据复现，再以回归测试证明正文深处证据可召回、预算与范围不变。
- [x] 对确认的问题做一次集中修复；运行对应测试后进行一次浏览器确认，不反复进行无依据的视觉微调。
- [x] 同步使用文档、验证证据及 GitHub 分支；正常便携构建、实际桌面与 MCP 烟测通过，入口和客户端连接已指向新包。主分支合并由本轮 PR 的 Quality checks 确认。

不加入额外模型，不扩大普通笔记的 AI 可见范围。Codex 钩子信任及 Claude 模型服务仍按用户安排等待，不将其标记为验收通过。依赖告警依据实际使用路径决定是否修复，不通过强制降级换取审计数字。
