# 聊天切换与草稿身份

场景：0.15 发布前云端浏览器检查中，“未发送草稿切换”首次失败、重试通过。检查代码发现新建/打开对话等待异步保存时，输入框仍可编辑，紧接着输入的文字可能写入旧对话。另一项浏览器重试发生在初始页面加载的 `ERR_NO_BUFFER_SPACE`，单独记录，不把它归因于业务逻辑。

- [x] 用延迟保存稳定复现切换中的输入/会话身份问题，覆盖保存失败；原版本实际将新输入写进旧草稿，修复后保留原文。
- [x] 切换和删除对话期间明确显示状态，暂时禁用编辑、发送和重复切换；等待完成后恢复；关闭窗口等待正在进行的切换。
- [x] 保留旧草稿，失败留在原对话；不修改数据库格式或增加依赖。
- [ ] 完成相关组件、浏览器、桌面与正式包验证，发布 0.15.1，并更新既有 Agent 的本应用连接路径。

0.15.0 已合并 PR #583 并发布；其资料检查、召回和真实升级验证保持有效。完整云端浏览器结果为 98 项首轮通过、2 项重试后通过，不能写成 100 项首轮无重试通过。此修补完成前整体目标继续进行。
