# 阅读与闲置性能优化（2026-10-16）

基点：0.13.0 / d811bde。用户确认先完成索引、草稿、撤销三项，再完成 AI 闲置刷新。不包含报告中独立列出的 PDF 批注、向量库替换和资源去重。

## 实施顺序与验收

- [x] 按用户最新要求停止人为堆量压测。验证少量文档的实际操作和数据结果，不追求极端规模指标。
- [x] 索引：收藏不重新核对正文；利用现有差量文件对象只检查变化项；串行合并队列，废弃旧结果；原生书房与搜索放入后台线程，保留授权。
- [x] 草稿：桌面原生逐条存储、浏览器 IndexedDB；只加载列表摘要和当前恢复正文；兼容旧 localStorage 草稿；保存/切换/关闭等待写入，失败保留原稿和旧数据，不自动淘汰。
- [x] 撤销：每文档及全局字节预算，连续小输入分组；撤销/重做、双窗格和中文输入保持一致，正文不纳入可淘汰历史。
- [x] AI：检测数据变化后刷新结果；隐藏空间/窗口暂停重复检索；恢复可见及时核对，保留跨 MCP 进程与时间到期发现。
- [ ] 回归：前端检查、原生、浏览器和桌面按顺序验证；记录前后测量及未覆盖的真实性能边界，更新使用/架构文档并同步 GitHub。

## 实现依据

[Tauri 后台命令](https://v2.tauri.app/develop/calling-rust/#async-commands)、[IndexedDB 事务完成与升级](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)。确认事务完成后才报告持久化成功；页面卸载不是可靠的异步保存时机。
