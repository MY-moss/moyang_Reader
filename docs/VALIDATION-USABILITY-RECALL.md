# 界面与记忆召回复核（2026-10-16）

本轮在根目录整合后的版本上复核。A 负责独立设计评审，B 负责检测器和浏览器证据；两者各用隔离浏览器，不共享初始发现，没有改动个人数据。

## 设计结论

保留暖白墨绿、正文优先、统一侧栏和固定双窗格。整体视觉一致，无需再次推倒重做。初始设计评分为 **28/40**，不是修复后的重新评分。

| 启发式       | 初始分数 /4 | 依据                                 |
| ------------ | ----------- | ------------------------------------ |
| 状态可见     | 3           | 保存、草稿、操作结果有文字反馈       |
| 用户语言     | 3           | 中文路径清楚，Agent 接入仍需解释     |
| 控制与自由   | 2           | 覆盖导航缺少键盘退出与焦点约束       |
| 一致性       | 3           | 两空间与市场共享视觉层级             |
| 预防错误     | 3           | 保留草稿、撤销和安装前说明           |
| 识别优于记忆 | 3           | 窄窗 AI 空库缺少开始提示             |
| 灵活与效率   | 3           | 快捷键、密度和双窗格入口完整         |
| 简洁与审美   | 3           | 正文突出，空库有不必要的分页         |
| 错误恢复     | 3           | 草稿可撤销；目录失败的重试入口不对应 |
| 帮助文档     | 2           | 应用内帮助原先只介绍阅读             |

阅读初见和正文体验安静明确；AI 窄窗空库是引导缺口。键盘用户会受覆盖导航焦点逃逸影响，首次使用者难从旧帮助了解 AI 与市场。市场安装前的来源、版本和作用说明值得保留。

## 确认的问题与修复

| 问题                               | 实际变化                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------ |
| 覆盖导航 Tab 进入背景，Escape 无效 | 复用模态行为，初始焦点、Tab 循环、Escape、暂时禁用背景及关闭后恢复入口焦点；放大窗口恢复普通侧栏 |
| AI 窄窗空库没有用途和连接指引      | 真正空库保留新建与连接入口，说明普通笔记独立；搜索无结果、归档不显示首次提示；单页不显示无效分页 |
| 帮助仅覆盖阅读，导出描述过时       | 阅读、AI、市场三个短主题，按当前页默认选择；说明接入、召回、插件命令、回退及真实导出入口         |
| 深色目录错误对比度 2.69:1          | 显式和系统深色均定义较亮的错误色；浅色维持原值                                                   |
| 目录请求失败却只提供读取本地状态   | 显示失败目录及已有安装仍可用，保留错误详情，直接重试原请求；错误时隐藏过时的成功通知             |
| 无空格长插件名挤出类型/状态        | 名称、描述允许断行；检查列表行自身宽度，避免只检查页面漏报                                       |
| 上下文功能文字 9–10px              | 状态、目录/关联/属性、进度操作提高到至少 12px；类型徽标不被文件名压缩                            |

CLI 仅扫描 src/shell，返回 0 项，不能推断整个产品无问题。浏览器检测覆盖阅读、AI、市场三页，注入成功，但浏览器无界面，用户没有看到实时覆盖层。排除了关闭菜单、隐藏空间造成的遮挡/字号误报，以及与指定暖白风格冲突的建议。两个代理的浏览器和检测服务已关闭。原始证据在本机 artifacts/usability-review/a、b，不进入源码仓库。

用户已授权补齐功能和修复实际问题，不重复征求风格或范围确认。Questions skipped: 已有明确的实施授权。

## 长期记忆的实际修复

隔离库保存一条末尾含“月石发布要求”的置顶记忆。旧版搜索能命中，但 recall_context 用开头摘要替换相关结果：返回 491 个字符、没有关键结论，也没有标记截断。

现在命中任务的置顶条目直接复用已有相关片段；未命中的偏好仍带简短开头。同一条目只出现一次，不新增模型调用、数据库查询或默认字符预算。相同 MCP 复现返回 1093 个字符，包含要求和来源，不需要读取整份长文。

新测试在修复前真实失败，修复后 AI 内核 45 项、stdio MCP 2 项通过。作用域、过期和按需读取约束继续由同组回归覆盖。此次只改上下文组装，未改变向量模型、搜索排名，也未把原 80 条调优集称为新的独立盲测。

启用真实 qwen3-embedding:0.6b 后，隔离库中同一场景也返回相关证据和唯一 ID。首次冷模型与桌面编译并行时超出探针的 20 秒限制；探针改用现有评测的 240 秒等待后通过，未修改产品超时。
