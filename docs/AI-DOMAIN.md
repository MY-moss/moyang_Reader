# AI 工作台术语与数据约定

| 术语            | 含义与边界                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------ |
| 资料 / 记录     | 一条知识、长期记忆或技能；拥有稳定 ID、当前修订、来源与共享范围。普通笔记不自动成为资料。        |
| 修订            | 正文或属性的已保存版本。局部更新必须带预期修订；未发生变化不增加版本。                           |
| 共享范围        | 全局、项目、旧 Agent 私有。全部资料是浏览筛选，不是写入范围。                                    |
| L0 目录         | 判断是否相关所需的标题、用途、范围、版本和可读层级。                                             |
| L1 概览         | 默认召回的核心内容、适用条件、来源及正文导航；短记忆可直接返回原文。                             |
| L2 正文         | 当前原文；支持章节、行范围、字符预算和固定修订的连续读取。                                       |
| L3 历史         | 先读取修订清单，再读取指定版本。四层是读取方式，不复制四份原文。                                 |
| 派生概览        | API 整理生成、绑定输入指纹的独立内容。原文变化后立即失效，不覆盖手写摘要，也不阻断原文检索。     |
| 上下文回执      | 本进程对同一上下文已发出修订的短期记录。压缩、重启、交接或项目切换后重建，不永久省略证据。       |
| 任务检查点      | 真实客户端、会话和原始轮次的稳定身份；重复回调不重复沉淀。                                       |
| 整理任务        | 按输入指纹合并的持久任务。桌面与 MCP 共用队列、互斥锁和每日额度；没有额外常驻服务。              |
| 预留 / 已用额度 | 请求前预留输入估算和输出上限；响应后按实际 usage 结算。失败、缺 usage 与中断保留估算，不记作零。 |
| 同义合并组      | 同范围、适用条件兼容的长期记忆产生新记录，原记录归档；保存来源、原修订和替代关系，支持整组撤回。 |
| 不可变资源      | 按编码与内容指纹去重的附件字节；当前资料、历史和冲突提议保存引用，按需读取。                     |
| 便携备份        | 带清单、校验和、逐条 SQLite 数据及去重资源的 ZIP。独立于普通笔记、聊天密钥及运行任务锁。         |
| 服务配置        | 聊天、整理和嵌入共享的 API 地址、协议和私密密钥；各用途分别选择模型。                            |
| 模型目录        | 本应用管理的 Ollama 模型文件位置，可与 AI 库分盘；运行内存需求与下载体积不是同一概念。           |

实现与取舍见 [分层与整理决策](adr/0005-layered-context-and-organizer.md)、[资源与备份决策](adr/0006-resources-and-portable-archive.md)。接口见 [MCP 指南](MCP-GUIDE.md)，用户入口见 [服务与模型说明](BACKGROUND-ORGANIZATION.md)。
