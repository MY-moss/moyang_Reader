# 知识来源批量核对（0.16）

在“近期活动与冲突 → 来源更新”按项目检查已导入知识的来源，查看差异后逐条更新快照。检查不会自动覆盖正文，不新增模型或推理链，也不扫描普通阅读库。

## 实现与取舍

| 场景                       | 行为                                                                                      |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| 来源较多                   | 来源清单分页读取，仅返回标题、范围、URI、指纹和版本；页面每页展示 30 项，所有匹配项可到达 |
| 主动检查                   | 最多两个来源并行读取，结果只保存轻量状态；查看比较时重新读取一份正文                      |
| 文件丢失、网页失败或空正文 | 标为无法读取，其他来源继续；原快照不变，可重试                                            |
| 停止检查或离开页面         | 停止调度新来源，丢弃迟到结果；已经结束的结果在当前页面保留                                |
| 确认更新                   | 保留标题、摘要、标签、范围和关联；正文与快照产生新修订，旧版本可恢复                      |
| 其他 Agent 同时修改        | 旧版本写入失败，比较内容保留；重新读取后再判断                                            |
| 旧 Agent 私有资料          | 清单沿用现有范围规则，不扩大旧记录共享方式                                                |
| MCP 使用                   | `list_knowledge_sources` 返回同一分页清单，不读取文件/网页，不调用模型或索引维护          |

来源检查结果属于本次页面会话；未变化的检查不制造无意义修订。浏览器导入只有文件名时，明确提示重新选择文件。网页正文提取继续使用现有导入模块，需登录或脚本执行的网页仍可能无法提取。

## 证据与边界

浏览器使用虚构的“来源样例.txt”，证据位于 `artifacts/source-review/`；只写浏览器隔离存储。原生测试使用本机临时 Markdown 和临时 HTTP 服务，验证真实读取、差异、并发保存与历史。私人资料与客户端配置不进入测试。

此项改善来源维护的便利性，不等同于来源真实可靠性审核。没有进行人为堆量压测，不推算大库速度或内存收益。Codex/Claude 的真实任务结束沉淀仍按用户此前安排保留待验收状态。
