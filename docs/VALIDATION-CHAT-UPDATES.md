# 0.13.0 聊天、在线更新、存储与 GitHub 整理

日期：2026-10-16。当前根目录工程，Windows x64。本报告只记录已实际执行的结果，未完成项保留说明。

## 交付能力

- 收拢工作台导航与管理项，统一 Lucide 图标，保持暖白墨绿、舒适/紧凑和浅深色。
- 市场提供可选书房聊天、阅读伙伴、翻译伙伴。自己的 OpenAI 兼容或 Anthropic 服务、多配置/模型、流式回答、停止、重试、历史、草稿恢复与导出；停用不删除会话。
- 用户显式选择项目记忆召回、附加当前文档或把回答存入知识/记忆。插件预设不接触宿主 API 密钥，普通笔记不自动发送。
- 独立签名的便携更新：启动检查、可选自动下载、明确重启、保存队列收尾、失败保留旧版本。模型不随小更新重复下载。
- 「设置 → 存储位置」统计真实占用，选择其他本机磁盘，检查空间与占用进程，复制校验后切换；原 MCP 路径保持可用，模型可选。没有擅自迁移用户实际资料。
- GitHub 的 10 个依赖 PR 集成到当前工程；修复 sha2 编译与 opener 两端版本兼容，补快速打开字号/深色与导航就绪回归。逐票依据见 [整理记录](GITHUB-MAINTENANCE-2026-10.md)。

## 实际边界

- API 两种协议使用本机 HTTP 服务夹具验证，覆盖中文分片、请求头、取消与错误；不代表用户任意转发服务都兼容。未接收或使用用户真实 API 密钥。
- Codex 的客户端信任与 Claude Code 的上游服务按用户要求继续暂缓，不声称两个真实 Agent 的自动沉淀已经验收。
- 0.13 是新签名渠道的首个版本；旧安装版的旧通道不指向这个包。真实 0.13 → 下一正式版本升级单独留在 #241，隔离升级演练不替代这一项。
- 当前程序没有商业 Authenticode 证书；更新签名与 SHA-256 已提供独立核验机制，说明见 [SECURITY](../SECURITY.md)。
- 存储迁移只支持 Windows 本机稳定磁盘。实际断电、移除磁盘、空间耗尽的物理故障未做破坏性试验；复制失败与切换回退逻辑有夹具验证。迁移可选择目标，但未替用户决定实际磁盘。
- 官方 npm 审计：运行依赖 0 高危/严重、3 中危（Mammoth 的命令行依赖链）；含开发依赖 22 高危、3 中危，主要来自 WebdriverIO 9 工具链。兼容补丁已更新；Tauri 适配器仍要求 WebdriverIO 9，未使用强制跨主版本替换。后续归入 #194，不把依赖扫描说成全绿。
- 当前中文完整度优先，AI/聊天/存储尚未全部英文化；125%/200% Windows 实机缩放未新增验收。前后端错误码与历史样式仍可继续收敛。它们已集中到 #194。
