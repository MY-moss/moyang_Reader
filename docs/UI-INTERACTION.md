# UI 与交互契约

## 布局职责

```text
顶部栏：打开、搜索、编辑、保存、导出、更新、设置
左侧栏：工作区、文件树、筛选、最近阅读库
中央区：标签页、阅读区、源码编辑器或所见即所得编辑器
右侧栏：目录、关联内容、属性摘要、阅读状态；关系图从关联视图打开
底部栏：路径、文档类型、字符统计、版本和当前状态
```

文件树和搜索结果采用单击打开；连续定位文档使用 `Ctrl+P` 快速打开或系统文件选择器的多选能力。工作区不提供无选择地批量制造标签页的“打开列表”入口，批量操作只保留有明确产物的导出流程。未打开阅读库或当前筛选没有可导出文档时，隐藏批量导出入口而不是展示全部禁用的选项。

“添加整个文件夹”在同一界面只保留一个可见入口：侧栏展开时由空白主区（未挂载阅读库）或阅读库侧栏（已挂载阅读库）承接；侧栏收起后由顶部按钮承接。已有阅读库时按钮明确写作“添加阅读库”，不再误导为会替换旧文件夹。最多同时保留 5 个阅读库，达到上限时按钮禁用并说明先移除旧库；切换菜单只切换当前活动阅读库，其他阅读库的文件树、筛选、标签页和当前文档会保留。快捷键 `Ctrl+Shift+O` 和命令面板入口始终保留，确保隐藏侧栏后仍可快速添加或切换阅读库。已有阅读库且尚未选中文档时，主区只引导从文件树或 `Ctrl+P` 开始阅读，不重复展示添加文件夹动作。

中央区只有一个主滚动容器；左右面板各自只保留根滚动容器，文件树、搜索结果和导出失败列表随面板自然展开，不再嵌套滚动。右侧面板在宽屏默认打开，在窄屏使用抽屉，不改变当前文档。面板内容默认隐藏横向溢出，长路径和长标题使用省略或换行保护布局。

左右面板与中央区之间提供原生指针拖拽边界：左栏宽度限制为 220–380px，右栏限制为 260–440px；双击边界恢复默认宽度（260px / 320px）。拖拽宽度、收起状态和右栏当前视图均只保存在本机 UI 偏好中，不影响文档内容。边界获得键盘焦点后，方向键按 16px 调整，Shift+方向键按 48px 调整，Home/End 直接到最小/最大值。

## 上下文菜单与快速新建

- 工作区存在时，侧栏“新建”菜单提供“新建笔记”和“新建文件夹”；笔记默认保存为 Markdown，并在创建成功后打开，文件夹直接写入用户选择的工作区。
- 根目录、任意真实文件夹和文件所在目录都支持右键或 `Shift+F10` / Context Menu 键，菜单只显示当前目录可执行的新建动作；不使用占位文件让空文件夹出现。
- 文件右键菜单提供“打开文件”“重命名文件”“删除文件”“在资源管理器中显示”和“复制完整路径”；文件夹提供对应的重命名、递归删除、资源管理器打开和路径复制动作。根目录不显示重命名/删除，但保留新建、定位和复制路径。
- 删除是不可逆操作，菜单触发后先显示确认；当前文档或被删除文件夹内的文档存在未保存修改时，追加保存确认，取消或保存失败都不得改变文件系统和当前标签页。
- 文件夹重命名后，文件树、打开标签、最近打开、当前文档和索引使用新路径；删除当前条目后优先打开相邻标签，否则显示空状态。失败原因通过底部/顶部状态提示呈现，不静默吞错。
- 文件管理命令只接受工作区相对路径并由 Tauri 端再次校验授权范围；最终符号链接不允许重命名或删除。资源管理器定位由隐藏控制台窗口的 Windows 调用完成，不额外弹出 CMD。
- 空文件夹仍须在文件树中显示；工作区启动、切换和 watcher 增量刷新都要同步目录状态。筛选工作区时只显示与当前结果有关的目录，避免筛选后出现大量无关空目录。
- 编辑模式下的 Markdown/WYSIWYG 和 TXT 源文本编辑器共用“编辑 / 格式 / 段落 / 插入”菜单，覆盖撤销、重做、剪切、复制、粘贴、全选、粗体、斜体、删除线、行内代码、标题、列表、引用、代码块、链接、双链、图片、表格和分隔线。菜单动作复用应用级历史、Milkdown/CodeMirror 命令，不新增重量级依赖。
- 菜单使用固定定位、视口边界修正、Escape/外点关闭、首项聚焦和上下方向键导航；阅读模式不拦截系统右键菜单。未知 Markdown 语法仍遵循源码回退规则。
- 标签页支持鼠标中键关闭；原生拖拽标签页可调整顺序，拖拽目标提供明确视觉反馈，外部文件拖放仍由应用根区域处理。
- 阅读缩放属于阅读视图偏好：设置滑块范围为 75%–150%，Ctrl+滚轮按 5% 连续调整，Ctrl+=/Ctrl+- 按 10% 调整，Ctrl+0 恢复 100%；缩放提示使用非打断式状态提示。

目录导航必须以当前文档的中央正文为范围，不使用全局 `document.getElementById` 或浏览器窗口滚动。点击目录项时由应用计算标题相对中央滚动容器的位置；正文采用渐进渲染时最多等待有限的动画帧，标题仍未出现则安全结束，不改变当前文档。源码或所见即所得模式点击目录时先切换到阅读模式，再执行同一导航流程。

## 面板状态

- `leftPanelOpen`：工作区导航是否显示。
- `rightPanelOpen`：上下文面板是否显示。
- `activeContextTab`：`outline`、`backlinks` 或 `properties`；关系图不是独立页签，从“关联”视图打开。
- `focusMode`：隐藏两侧面板和底部状态栏，只保留正文。

面板状态只保存 UI 偏好，不保存文档正文。右栏的标签点击可以改变左栏筛选，但不会自动切换当前文档；目录、反向链接和关系图的打开动作必须明确指向目标文档。

## 文档模式

| 文档          | 默认     | 可用操作                         |
| ------------- | -------- | -------------------------------- |
| Markdown      | WYSIWYG  | 编辑、源码切换、保存、双链和导出 |
| TXT/LOG       | Source   | 纯文本编辑、保存和导出           |
| DOCX/PDF/图片 | Rendered | 预览、复制或导出，不显示编辑入口 |

Markdown 打开后，顶部的“编辑”是高频主动作；进入编辑后按钮变为“阅读”，`Ctrl+E` 与它保持同一读写切换语义。源码切换属于保真/排障动作，继续放在“更多”菜单，不与主动作争夺视觉权重。所见即所得的每次输入先更新当前草稿和预览，磁盘写回仍需用户明确保存，避免自动覆盖外部修改。

## 状态反馈

必须区分：读取中、索引中、可编辑、未保存、保存中、外部修改、保存失败、更新可用和导出中。错误提示应说明影响和下一步，不只显示异常字符串。
设置面板另外显示“正在保存设置 → 设置已保存到本机”的短状态；桌面端写入应用配置文件作为本机兜底。若浏览器存储或应用配置文件任一层失败，显示“使用本机备用存储”；两层都失败时显示保存失败，不使用会推动主布局的全宽通知条冒充成功反馈。
文档、标签或阅读库发生切换前，若当前文档存在本地未保存编辑，先同步冲刷最新草稿再询问用户；成功后提示“已自动保留为草稿，可在草稿中心恢复”，失败则停留在当前文档并提示先手动保存。浏览器临时预览无法持久化草稿时，继续使用“未保存修改将丢失”的保护文案。
外部修改分两种路径：无本地修改时静默刷新当前内容；有本地修改时保留当前编辑并显示冲突提示。重新载入动作必须先留下可恢复草稿并要求确认。

冲突提示的“稍后处理”只收起提示，不清除文档的外部修改标记；标题、当前标签、正文信息和状态栏保留标记，点击标记可重新打开处理选项。普通保存会再次打开处理选项而不是覆盖文件。处理选项固定包含“重新载入”“覆盖保存”“另存为”；覆盖保存先显示应用内确认对话框，避免使用无法被桌面自动化稳定验证的原生确认框。

更新下载进行中显示“下载中…”和进度；用户可以隐藏更新提示，但下载继续运行，顶部更新入口可重新打开进度。隐藏与关闭更新资源是两个不同动作，下载期间不能调用关闭资源的清理逻辑。“启动时检查更新”设置只影响下一次启动，不能因运行中切换设置而立即触发检查。

## 模态弹层

所有带 `aria-modal="true"` 的弹层共享同一套键盘契约：打开时聚焦明确的初始控件；`Escape` 只关闭当前弹层；`Tab`/`Shift+Tab` 在弹层内部循环；卸载后焦点归还到原触发控件。命令面板和快速打开保留上下键/Enter 导航，关系图、打印预览、草稿恢复和确认弹层保留各自的业务按钮。弹层外的页面快捷键不能因 Esc 冒泡而误触发。
首次使用教程遵循同一契约，提供打开文档、添加阅读库和完成引导三个动作；关闭后可从空白页或设置重新打开，不记录或上传文档正文。

## 快捷键

现有 `Ctrl+O`、`Ctrl+Shift+O`、`Ctrl+P`、`Ctrl+F`、`Ctrl+Shift+B`、`Ctrl+Shift+Enter` 保持兼容；新增 `Ctrl+Shift+R` 用于右侧上下文面板，另有 `Ctrl+E`、`Ctrl+Shift+P`、`Ctrl+S`、`Ctrl+K` 和编辑器内的 `[[`/`/` 触发器。所有快捷键统一经过命令注册表，并在输入框、CodeMirror 和所见即所得编辑器内正确让渡。

## 视觉规则

- 正文使用最高对比和最大留白。
- 表面层级最多三层，阴影只用于浮层、对话框和当前活动区域。
- 使用稳定的 `:focus-visible`、禁用、加载和成功状态，不依赖颜色 alone。
- 动画只用于面板展开、状态变化和加载反馈；遵守 `prefers-reduced-motion`。
