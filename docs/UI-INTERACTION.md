# UI 与交互契约

## 布局职责

```text
顶部栏：打开、搜索、编辑、保存、导出、更新、设置
左侧栏：工作区、文件树、筛选、最近阅读库
中央区：标签页、阅读区、源码编辑器或所见即所得编辑器
右侧栏：目录、关联内容、属性摘要、阅读状态；关系图从关联视图打开
底部栏：路径、文档类型、字符统计、版本和当前状态
```

文件树和搜索结果采用单击打开；连续定位文档使用 `Ctrl+P` 快速打开或系统文件选择器的多选能力。工作区不提供无选择地批量制造标签页的“打开列表”入口，批量操作只保留有明确产物的导出流程。未打开阅读库或当前筛选没有可导出文档时，隐藏批量导出入口而不是展示全部禁用的选项。

“添加整个文件夹”在同一界面只保留一个可见入口：侧栏展开时由空白主区（未挂载阅读库）或阅读库侧栏（已挂载阅读库）承接；侧栏收起后由顶部按钮承接。已有阅读库时按钮明确写作“添加阅读库”，不再误导为会替换旧文件夹。最多同时保留 5 个阅读库，达到上限时按钮禁用并说明先移除旧库；切换菜单只切换当前活动阅读库，其他阅读库的文件树、筛选、标签页和当前文档会保留。快捷键 `Ctrl+Shift+O` 和命令面板入口始终保留，确保隐藏侧栏后仍可快速添加或切换阅读库。已有阅读库且尚未选中文档时，主区只引导从文件树或 `Ctrl+P` 开始阅读，不重复展示添加文件夹动作。

中央区只有一个主滚动容器；左右面板独立滚动。右侧面板在宽屏默认打开，在窄屏使用抽屉，不改变当前文档。

## 面板状态

- `leftPanelOpen`：工作区导航是否显示。
- `rightPanelOpen`：上下文面板是否显示。
- `activeContextTab`：`outline`、`backlinks` 或 `properties`；关系图不是独立页签，从“关联”视图打开。
- `focusMode`：隐藏两侧面板和底部状态栏，只保留正文。

面板状态只保存 UI 偏好，不保存文档正文。右栏的标签点击可以改变左栏筛选，但不会自动切换当前文档；目录、反向链接和关系图的打开动作必须明确指向目标文档。

## 文档模式

| 文档          | 默认     | 可用操作                         |
| ------------- | -------- | -------------------------------- |
| Markdown      | WYSIWYG  | 编辑、源码切换、保存、双链和导出 |
| TXT/LOG       | Source   | 纯文本编辑、保存和导出           |
| DOCX/PDF/图片 | Rendered | 预览、复制或导出，不显示编辑入口 |

Markdown 打开后，顶部的“编辑”是高频主动作；进入编辑后按钮变为“阅读”，`Ctrl+E` 与它保持同一读写切换语义。源码切换属于保真/排障动作，继续放在“更多”菜单，不与主动作争夺视觉权重。所见即所得的每次输入先更新当前草稿和预览，磁盘写回仍需用户明确保存，避免自动覆盖外部修改。

## 状态反馈

必须区分：读取中、索引中、可编辑、未保存、保存中、外部修改、保存失败、更新可用和导出中。错误提示应说明影响和下一步，不只显示异常字符串。
文档、标签或阅读库发生切换前，若当前文档存在本地未保存编辑，先同步冲刷最新草稿再询问用户；成功后提示“已自动保留为草稿，可在草稿中心恢复”，失败则停留在当前文档并提示先手动保存。浏览器临时预览无法持久化草稿时，继续使用“未保存修改将丢失”的保护文案。
外部修改分两种路径：无本地修改时静默刷新当前内容；有本地修改时保留当前编辑并显示冲突提示。重新载入动作必须先留下可恢复草稿并要求确认。

冲突提示的“稍后处理”只收起提示，不清除文档的外部修改标记；标题、当前标签、正文信息和状态栏保留标记，点击标记可重新打开处理选项。普通保存会再次打开处理选项而不是覆盖文件。处理选项固定包含“重新载入”“覆盖保存”“另存为”；覆盖保存先显示应用内确认对话框，避免使用无法被桌面自动化稳定验证的原生确认框。

更新下载进行中显示“下载中…”和进度；用户可以隐藏更新提示，但下载继续运行，顶部更新入口可重新打开进度。隐藏与关闭更新资源是两个不同动作，下载期间不能调用关闭资源的清理逻辑。“启动时检查更新”设置只影响下一次启动，不能因运行中切换设置而立即触发检查。

## 模态弹层

所有带 `aria-modal="true"` 的弹层共享同一套键盘契约：打开时聚焦明确的初始控件；`Escape` 只关闭当前弹层；`Tab`/`Shift+Tab` 在弹层内部循环；卸载后焦点归还到原触发控件。命令面板和快速打开保留上下键/Enter 导航，关系图、打印预览、草稿恢复和确认弹层保留各自的业务按钮。弹层外的页面快捷键不能因 Esc 冒泡而误触发。

## 快捷键

现有 `Ctrl+O`、`Ctrl+Shift+O`、`Ctrl+P`、`Ctrl+F`、`Ctrl+Shift+B`、`Ctrl+Shift+Enter` 保持兼容；新增 `Ctrl+E`、`Ctrl+Shift+P`、`Ctrl+S`、`Ctrl+K` 和编辑器内的 `[[`/`/` 触发器。所有快捷键统一经过命令注册表，并在输入框、CodeMirror 和所见即所得编辑器内正确让渡。

## 视觉规则

- 正文使用最高对比和最大留白。
- 表面层级最多三层，阴影只用于浮层、对话框和当前活动区域。
- 使用稳定的 `:focus-visible`、禁用、加载和成功状态，不依赖颜色 alone。
- 动画只用于面板展开、状态变化和加载反馈；遵守 `prefers-reduced-motion`。
