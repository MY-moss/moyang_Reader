## 切片 1：范围、活动和读取维护

- 已修复项目导入被自动写到全局：文件、网页、目录导入共用可恢复草稿，显示目标范围，明确确认后入库。正常新建仍自动保存。
- 活动、资料检查与来源页跟随现有变化通知；隐藏页面不重复搜索正文。活动按范围分页，待处理检查点与已完成记录不重复；冲突展开才读取正文。
- 普通 MCP 读取、桌面统计不再启动索引维护；实际写入后只填缺失向量，已有完整向量不探测模型；失败自动维护退避 60 秒，手动重试仍可用。
- MCP 搜索片段只保留一份正文；原有 excerpt / quote 字段保留为空字符串，定位保留来源、指纹和页码。关键词投影不加载技能附件。
