# 隐私说明

Moyang Reader 是本地优先的阅读器，不要求登录，也不会把本地 Markdown、Word、PDF 或图片内容上传到 Moyang Reader 服务。

## 会访问网络的情况

- 用户开启“启动时检查更新”后，应用会从 GitHub Releases 检查更新；更新包必须通过内置公钥验证后才会安装。顶部“更新”按钮始终可以手动检查。
- 如果文档包含 `http://` 或 `https://` 的远程图片或嵌入资源，且用户在设置中允许远程图片，应用所在 WebView 可能按文档内容访问对应站点。
- 点击文档中的 `http(s)`、`mailto` 或 `tel` 链接时，应用会交给系统默认程序打开，不会让 Moyang Reader 主窗口导航到外部网页；不支持的协议会被拦截。
- 应用不会因为打开普通本地文档而主动上传文档内容。

## 本地保存的数据

- 最近打开的文件、最后阅读文档、阅读库路径和有限的滚动位置保存在应用本地存储中；只保存路径与位置，不保存文档正文，恢复前会在本地重新确认路径存在和格式受支持。
- 编辑保存时会短暂创建备份文件和临时文件，以减少写入中断造成的丢失风险。
- 更新私钥不属于应用数据，不能放进仓库、安装包或公开文档；发布流程只使用本机安全文件和 GitHub Actions Secret。

## 用户控制

用户可以在顶部“设置”中关闭远程图片和启动更新检查，也可以移除最近记录或删除本地备份文件。两项偏好只保存在本机，不会上传到服务端。
