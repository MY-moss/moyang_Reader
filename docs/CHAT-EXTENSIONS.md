# 可选聊天助手与自己的 API

## 开始使用

打开「插件市场」，安装 **书房聊天**、**共读伙伴** 或 **双语阅读**，点击「开始聊天」。入口会出现在 AI 空间。没有安装聊天助手时，原来的阅读、知识、记忆和技能功能保持独立。

0.14 另提供 **论证审阅**（核对主张与证据）和 **复习教练**（一问一答的主动回忆）。它们使用同一套 API 配置，不需要额外模型；没有附加资料时会先索要材料。复习教练不提供自动提醒，来源核对技能也不会自行获得文件或网络权限。

在「API 服务」添加自己的配置：服务名称、协议、API 基础地址、密钥与默认模型。支持 OpenAI 兼容 Chat Completions 和 Anthropic Messages 流式协议；可配置多个服务，并在对话底部切换服务或填写模型 ID。服务不提供模型列表时，直接手动填写。选择「设为默认服务」只影响新对话。

- OpenAI 官方地址示例：`https://api.openai.com/v1`。
- Anthropic 官方地址示例：`https://api.anthropic.com/v1`，选择 Anthropic Messages 协议。
- 本地 Ollama 示例：`http://127.0.0.1:11434/v1`，选择 OpenAI 兼容协议，使用你已有的聊天模型；嵌入模型不能用于聊天。
- 转发服务使用该服务提供的基础地址与模型 ID。不要把密钥写在网址参数里。

「获取模型」与「测试回答」会请求所选服务，测试回答可能产生少量用量。填写配置本身不会调用模型。API 密钥在桌面版本机的独立配置库保存，不显示在服务列表中，也不包含在聊天导出或助手包里。它不是加密保险箱；请按个人电脑的方式保管本机数据。

浏览器预览的密钥仅在当前页面暂存，刷新后需重填；API 服务必须允许浏览器跨域请求。桌面版通过原生网络请求，不受浏览器跨域策略限制。

## 对话、资料与记录

0.15.3 起，API 服务表单有未保存修改时，返回聊天、新增或切换服务会先提供“保存后继续 / 放弃修改并继续 / 继续编辑”。保存失败留在当前表单并保留填写内容；尚未保存的密钥不会写入浏览器草稿。获取模型与测试回答仍会先保存服务配置。

Enter 换行，Ctrl / Command + Enter 发送。中文输入法组词期间不会误发送。回答可随时停止；网络失败保留已收到的文字与问题，可重新回答。历史对话本地保存，可打开、删除和导出 Markdown。生成中可以切换阅读或资料页面，返回后继续查看。

0.15.1 起，新建、打开或删除对话等待本机保存时显示“正在保存并切换对话”，输入和发送暂时停用，完成后恢复，避免紧接着输入的文字写到上一份草稿。保存失败会留在原对话并保留草稿；关闭或更新应用会等待正在进行的切换。

默认只发送聊天内容。「附加当前文档」可选择当前 MD、TXT 或 DOCX 的全文、章节或已选文字，发送前预览、修改和移除；单次引用最多 12000 字符并显示截取提示。不把 PDF 原文件、图片或其他未选择的普通笔记自动发送给服务。

「AI 库召回」默认关闭。开启后，相关知识与长期记忆会随请求发给当前 API：项目留空只使用全局资料；填写项目后使用该项目及全局资料。回答下方可展开查看实际使用的文本。浏览器预览提供关键词召回，桌面版沿用完整本地召回流程。

点击「预览上下文」可逐条检查来源、范围和层级，取消勾选不想发送的条目，或打开原文。发送前核对资料变化，发现更新时重新召回；同一内容按指纹去重，历史中反复附加的同一正文只拼入请求一次。单次请求预算约 24000 字符，召回总预算 5000 字符。预览的 token 数为估算，服务实际 usage 单独显示，不估算价格。过长历史从最早消息起省略并提示，完整历史仍在本机；不额外调用总结模型。

草稿按对话异步保存，关闭时等待写入；打开历史先载入 20 条摘要，点击「加载更多」继续。服务配置也可在「设置 → AI 服务与整理」管理，未安装聊天插件仍可用于整理和嵌入检索。

回答需要成为知识或长期记忆时，点击「存入 AI 库」，编辑正文并确认。记录保留对话来源；不会把未经确认的模型猜测自动写成长期事实。

## 助手扩展

聊天助手是一种 `assistant` 扩展，声明提示词与最多 8 条建议问题。可与阅读插件、主题、技能、MCP 一样导入、导出、升级、停用和回退。助手包不包含 API 密钥，也没有自行调用 API、执行本机命令或修改文件的能力；实际请求由宿主的聊天服务完成。

卸载或停用助手不删除历史或服务配置。重新启用任意聊天助手即可查看旧记录；继续对话前选择一个已启用的助手。

```json
{
  "format": "moyang-extension",
  "id": "my.reading-helper",
  "name": "我的阅读助手",
  "version": "1.0.0",
  "minAppVersion": "0.13.0",
  "kind": "assistant",
  "author": "我",
  "description": "围绕资料讨论，区分来源与推测。",
  "assistant": {
    "prompt": "帮助我读懂资料。引用所提供的来源，不确定时明确说明。",
    "starters": ["这篇文章的核心论证是什么？"]
  }
}
```

## 数据与恢复

桌面聊天存储在应用配置目录下的 `chat/chat.sqlite`，与 AI 空间和普通文档分别保存。关闭应用后，备份整个 `chat` 目录即可保留服务、密钥和历史；因此该目录属于私人数据，不上传 GitHub。恢复时先关闭应用，再放回备份。单条聊天的 Markdown 导出仅用于阅读，不包含 API 密钥，不是完整数据库恢复包。

浏览器预览使用当前浏览器的 `moyang-chat` IndexedDB。清除网站数据会删除这些预览记录。普通设置导出和 AI 库备份不包含聊天数据库。

## 协议依据与边界

实现参考 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat) 与 [Anthropic 流式消息](https://platform.claude.com/docs/en/build-with-claude/streaming)，处理分段 UTF-8、错误、结束事件与取消。当前支持文字对话；工具执行、多模态上传、Responses API 专属服务和模型推理过程显示不在此轮实现范围内。
