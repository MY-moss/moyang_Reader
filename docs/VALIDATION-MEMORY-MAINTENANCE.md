# 资料检查与召回预算验证（0.15.0）

## 场景与实现

资料增长后，过期、缺少来源、重复正文和失效关联不易集中发现。新增按项目检查入口与 MCP `library_health`，保持日常笔记隔离，使用现有 SQLite，不引入模型或新的后台任务。候选供整理，不能据此断言记录错误；归档和撤销使用现有修订检查。

旧召回顺序拼接完整来源和最多四段正文，一条长记录即可消耗预算。现在给条目分配空间，缩短标题/来源，标明项目范围，在被缩短的片段中优先保留查询相关窗口。技能仍只返回摘要与按需读取提示，保留相同的项目、有效期和置顶规则。

## 边界

只识别同范围内正文相同的候选，不执行语义近似去重或推断矛盾；来源存在不等于已核验真实性。不会联网检查 URL，也不因长期未使用自动淘汰记忆。查询预算裁剪使用关键词窗口，纯语义命中的无关键词片段保留其开头，完整原文按 ID 读取。暂不声称独立盲测质量或大库性能收益。

真实 Codex 任务结束钩子及 Claude 全流程继续按用户安排等待客户端条件。普通使用验证不包括人为规模压测。
