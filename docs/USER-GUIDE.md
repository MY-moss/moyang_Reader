# Moyang Reader 使用教程

这是一份给第一次使用 Moyang Reader 的 Windows 用户的快速指南。Moyang Reader 是本地优先的阅读器：文档仍保存在原来的文件夹中，应用只记录阅读偏好、工作区路径和标签页状态，不会上传文档正文。

## 1. 第一次打开

首次启动会自动显示“快速上手”教程。以后可以从空白页的“查看使用教程”打开，也可以打开顶部“更多 → 设置 → 使用教程”。教程可以随时重新打开，不会影响文档内容。

如果安装后双击 `.md`、`.markdown`、`.txt`、`.docx`、`.pdf` 或常见图片文件，Windows 会把文件交给 Moyang Reader。也可以把文件直接拖入窗口，或者点击顶部“打开”。

## 2. 添加一个或多个文件夹

1. 点击顶部“文件夹”，或按 `Ctrl+Shift+O`。
2. 选择一个文件夹后，Moyang Reader 会把它作为一个阅读库递归扫描。
3. 从左侧文件树点击文档即可打开。
4. 再次添加其他文件夹即可同时保留多个阅读库；在左侧阅读库切换菜单中切换，不会清空其他阅读库的标签页和筛选状态。

文件夹也可以直接拖入窗口。最多同时挂载 5 个阅读库；移除阅读库只移除应用记录，不删除磁盘文件。

## 3. 阅读和编辑

- Markdown 默认打开为阅读视图；点击顶部“编辑”或按 `Ctrl+E` 进入所见即所得编辑。
- 复杂 Markdown、未知 HTML 或暂不支持的结构会自动回退到“源文本”模式，避免静默丢失内容。
- 当前 HTML/HTM 只作为导出目标，尚不能直接加入阅读库打开；安全 HTML 预览和源码编辑已列入后续路线。
- TXT、TEXT、LOG 使用纯文本编辑；Word、PDF 和图片当前是只读预览。
- 按 `Ctrl+S` 写回原文件。文档有外部修改时，先在提示中选择重新载入、覆盖保存或另存为。
- `Ctrl+Z` / `Ctrl+Y` 撤销或重做时会保留当前阅读位置。

常用 Markdown 能力包括标题、列表、表格、代码块、数学公式、YAML frontmatter、`[[文档]]` 双链和相对图片。输入 `[[` 可打开双链补全，输入 `/` 可打开块级命令。

## 4. 右键快速管理

- 在左侧文件树中右键文件夹，可在当前目录新建笔记/文件夹、重命名、删除整个文件夹、刷新文件夹、打开资源管理器、复制名称或复制路径。
- 右键文件可打开、关闭当前标签、重命名、删除、刷新所在文件夹、在资源管理器中定位、复制名称或复制完整/相对路径；重命名时直接输入完整文件名，不输入扩展名会自动保留原扩展名。
- 右键文件或文件夹还可以选择“查看属性”，查看类型、工作区路径、完整路径和文件大小/文件数；这个窗口只读，不会修改文件。
- 删除不可撤销。若当前文档有未保存修改，应用会先询问是否保存；取消或保存失败时不会删除磁盘文件。
- 标签页右键可以关闭当前、其他、右侧或全部标签；遇到未保存内容时会复用保存确认。
- 在 Markdown 或 TXT 编辑区右键，可使用撤销、重做、剪切、复制、粘贴、全选、查找选中文本，以及格式、段落和插入动作。阅读模式正文右键还可复制/查找选中文本、复制或打开链接、进入编辑和复制文档路径。

## 5. 找文档和看上下文

- `Ctrl+P`：按文件名或路径快速打开。
- `Ctrl+F`：查找当前文档内容。
- `Ctrl+Shift+P`：打开命令面板。
- 右侧上下文面板提供目录、关联和属性摘要；目录点击会在中央阅读区定位到对应标题。
- 左侧和右侧面板都可以拖动边界调整宽度；双击边界恢复默认值。
- `Ctrl+Shift+B` 切换左栏，`Ctrl+Shift+R` 切换右栏，`Ctrl+Shift+Enter` 进入专注阅读，`Esc` 退出。

## 6. 设置与保存

顶部“更多 → 设置”可以调整：

- 界面语言、主题、字号和正文宽度；
- 远程图片访问和启动时检查更新；
- PDF/打印纸张、方向和页边距；
- 设置备份的导出和导入。

设置会在修改后短暂显示“正在保存设置…”，成功后显示“设置已保存到本机”。桌面版会同时写入应用配置文件，写入过程使用临时文件和原子替换；浏览器存储不可用时会自动使用该配置文件作为备用存储。若两种本地存储都失败，设置面板会显示“设置保存失败”，不会假装保存成功。

设置备份 v2 还会包含最多 32 条阅读位置和本机书签，因此更换电脑或重装后可以继续上次阅读。备份仍不包含文档正文、草稿或私钥；导入旧版 v1 备份时，现有本机阅读位置和书签会保留。导入后，原文件夹路径仍需要 Windows 重新授权。

## 7. 导出和分享

顶部主按钮可以打印或保存 PDF；“导出”菜单还支持 Markdown/文本、HTML 和 Word（DOCX）。打印前可以先打开版式预览，确认目录、纸张、方向和页边距。

导出失败时先查看失败清单中的文件名和原因。导出不会修改原文档；生成的文件可以直接转发给其他人。

## 8. 更新

顶部“更新”可以手动检查 GitHub Release。发现新版本后，应用会下载签名安装包，校验通过后自动重启。更新只替换应用文件，不会删除阅读库或文档。

## 9. 遇到问题时

- **文档打不开**：确认扩展名受支持，并重新选择文件或文件夹；最近路径失效后需要重新授权。
- **设置重启后恢复默认**：打开设置观察保存状态；如果显示失败，先导出当前设置备份，再检查应用配置目录权限并重启应用。
- **看不到刚添加的文件**：等待左侧索引完成，或重新添加/刷新阅读库；应用不会扫描不支持的扩展名。
- **更新失败**：保留当前版本，等待更高补丁版本；不要把签名文件或私钥放入文档、Issue 或仓库。
