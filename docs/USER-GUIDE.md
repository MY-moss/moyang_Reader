# 使用指南

0.12 增加侧栏底部的“插件市场”：发现、安装和管理阅读插件、主题、AI 技能与 MCP。具体步骤见 [扩展指南](EXTENSIONS.md)。设置或市场打开时点击空间导航，会进入相应内容；Ctrl+Shift+F 在当前空间打开搜索，AI 连接页也可直接跳回搜索。

## 这次重构新增的操作

侧栏顶部切换阅读空间和 AI 空间。阅读空间依次提供最近打开、收藏、摘录与批注、保存的视图、恢复中心和文件树；设置与帮助固定在底部。两类内容独立保存，阅读库不会自动成为 AI 知识库。

单击文件树中的文档使用临时标签；打开另一份文档会复用这个标签。双击标签或开始编辑后保留。文档工具栏的双窗格按钮用于并排查看，可以交换两侧或调整比例；两侧打开同一文件时共用正文和保存状态，各自保留阅读位置。窄窗口暂时收起侧栏，左上角可重新展开，不改变桌面布局偏好。

全文搜索位于侧栏，也可按 Ctrl+Shift+F。结果包括 Markdown、TXT、Word 和文字 PDF，每份文件可显示多个命中；点击片段进入对应段落或物理页。搜索时可按类型、标签和排序保存视图，也能收藏整个搜索。扫描 PDF 需要文字层，本轮没有 OCR。

文档工具栏的书签保存选中文字或当前可见段落；引号按钮添加摘录和批注，PDF 使用页级来源。来源变动时尝试用引用文字重新定位，找不到或有多个匹配会提示核对。恢复中心提供回收站内容预览和文档历史比较；历史版本放入编辑器后可继续调整，并按正常自动保存流程写回。

- **文档属性**：打开 Markdown，切到右栏“属性”，点击“编辑文档属性”。常用标题和标签可直接填写，其他字段在“更多属性与源格式”中编辑；支持 YAML 列表与嵌套信息。应用后在源文本中继续编辑，按 Ctrl+S 保存。属性修改与正文共用草稿、撤销和外部修改保护。
- **正文与编辑字体**：侧栏设置 → 外观 / 编辑。本机字体优先，不下载网络字体。
- **命令搜索**：Ctrl+Shift+P，输入“保存”、`baocun` 或 `bc` 都能找到保存；`ksdk` 找到快速打开。最近执行的命令优先显示。
- **导出版式**：侧栏设置 → 导出版式，选择书籍阅读、工作报告或紧凑讲义，再导出 HTML、Word 或 PDF。版式只改变产物，原文不变。
- **关系图筛选**：右栏关联 → 关系图，可选整库/当前关联、标签和链接方向，输入标题或路径；多于 24 篇时翻页查看。
- **大阅读库**：文件树自动按视口绘制，不减少可访问文件。除了滚动，聚焦列表后可用上下方向键、Home、End 导航；Ctrl+P 仍可直接找全文档集合。
- **保存反馈**：底部显示正在保存、已保存或失败重试。保存期间的新输入仍属于未保存修改；浏览器模式显示已下载副本，不声称已写回原文件。

### 块引用与文档嵌入

```markdown
需要引用的一段正文。 ^idea

[[#^idea|跳到这一段]]
[[其他笔记#^summary|跳到另一份文档的摘要]]

![[#^idea]]
![[其他笔记]]
![[其他笔记#章节标题]]
![[其他笔记#^summary]]
```

块 ID 使用字母、数字、下划线或连字符，放在段落末尾，同一文档保持唯一。章节锚点以正文实际生成的锚点为准。跨文档嵌入需要桌面版的本地路径授权；找不到文件或目标时显示原因。为避免循环和过量加载，嵌入只展开一层，内部嵌入转为可打开的链接，单个源文档超过 2 MB 时请单独打开阅读。

## 打开与阅读

桌面版执行 `npm run desktop`。点击“打开文档”或按 Ctrl+O，可以选择多个文件。也可以把文件或整个文件夹拖入窗口。新打开的 Markdown 默认直接编辑；特殊语法自动使用源码模式。TXT 直接编辑，Word、PDF 与图片以阅读为主。

Markdown 支持常用表格、任务列表、公式和双链。Word 以转换后的内容阅读，不保证复杂分页、浮动对象与原 Word 逐像素一致。PDF 使用本地 PDF.js 阅读器，可输入页码、前后翻页与缩放。图片直接预览。

阅读时，Ctrl+F 查找当前文档；右侧目录跳转章节；Ctrl+Shift+Enter 进入专注模式，Esc 退出。Ctrl+滚轮调整阅读缩放，设置中可调整正文宽度。最近文件和阅读位置保存在本机。

## 管理阅读库

在欢迎页点击“添加整个文件夹”，或按 Ctrl+Shift+O。左侧会显示真实文件夹层级，随后建立关联索引。文件不复制进应用，也不会转换成私有格式。

单击文件即可打开。Ctrl+P 按名称或路径快速寻找文档；左侧搜索查找工作区正文。可以按格式和标签筛选，清除筛选后恢复完整列表。阅读库切换菜单支持多个资料库，各自保留会话。

文件树右键提供新建、复制、重命名、删除、路径复制和详情等操作。重命名维护可唯一确定的 Markdown 链接；歧义会列出。删除移入阅读库回收站，默认保留 30 天；恢复遇到同名文件会保留双方。外部程序增删改文件后，目录通过监听更新。

## 编辑与保存

阅读 Markdown 或文本时，点击文档上方“编辑”或按 Ctrl+E。Markdown 使用所见即所得编辑器；不适合安全往返的语法会回退源码。可在文档上方直接切换到源文本，保留完整 Markdown 控制。

修改后文档工具条显示“保存”，Ctrl+S 写回原文件。切回阅读可预览未保存草稿。Ctrl+Z 撤销，Ctrl+Y 重做。停止输入约 1.2 秒自动保存，中文输入法组词期间暂停。切换文档保留会话并继续保存；关闭标签和应用先完成保存，遇到冲突或失败时保留草稿并提示。

若文件被外部修改，可进入“比较与合并”，对照草稿、外部内容和共同版本后采用合并结果，也可另存副本或确认覆盖。重新读取前会尽量保存本地草稿。不要把自动草稿当作文件备份；重要内容仍应及时保存，并保留自己的备份。

浏览器预览不能像桌面版一样任意写回原文件；导出会下载新文件。

## 双链与关联

在 Markdown 中使用 `[[文档]]`、`[[文档|别名]]` 或章节链接，在阅读库内打开关联文档。右侧“关联”显示出链和反向链接，“属性”显示文档属性。未解析链接可创建新文档，图形入口可查看当前文档的一跳关系。

## 导出

打开“更多”，可复制内容、导出 Markdown/文本、HTML（含图片）和 Word。打印/PDF 入口根据桌面或浏览器环境提供相应能力。导出菜单中先“预览打印版式”，设置可选择纸张、方向和页边距。

资料库的批量导出遵循当前筛选范围。进度区可以取消，失败清单列出文件及原因；不支持的格式不会被伪装成成功。大批次可能分卷输出。

## 设置与恢复

侧栏“设置”可调阅读缩放、正文宽度、导出格式与语言；“更多”可切换系统/浅色/深色主题。远程图片默认关闭，主动开启后文档可能向外部图片站点发起请求。

设置导出生成 JSON，导入前会验证格式。开发版使用独立桌面身份，可以从旧版主动导出并导入设置。新版本不会自动搬走原文件。

有未保存草稿时，恢复中心提供草稿入口，可以恢复、暂缓或丢弃指定草稿。0.13.1 起桌面版逐篇存入本机阅读数据库，浏览器预览使用 IndexedDB；列表只读取摘要，打开时才读取完整正文。旧草稿自动导入一次并保留旧副本；丢弃后的草稿不会因重启重复出现。

草稿不再限制为最近 8 篇，也不会为新草稿自动删除其他未保存内容。总容量预算为 256 MiB，每篇原文和草稿各最多 800 万字符；达到容量或写入失败时保留当前窗口内容并提示手动保存。关闭桌面窗口前会等待保存结果。浏览器强制退出或系统断电不能保证最后一刻的输入已落盘，请留意保存状态。

撤销按连续输入分组，停顿、换行或撤销后重新编辑会形成独立步骤。每份文档保留最多 100 步并设 16 MiB 历史预算，所有打开文档合计 64 MiB；超出时先释放较早或非当前文档的撤销记录，当前正文和恢复草稿不被删除。

在线更新入口位于设置，支持检查、下载并在保存后重启；详见[在线更新](ONLINE-UPDATES.md)。

## 常用快捷键

窄窗口的覆盖导航支持 Tab / Shift+Tab 在导航内切换，Escape 关闭并回到入口；放大窗口后恢复普通侧栏。侧栏“使用帮助”按当前页面打开阅读、AI 或插件市场主题，也可以在帮助中切换。

设置与插件市场打开时，侧栏只高亮当前页面；返回工作台恢复之前的内容。在窄窗口的设置页，左上角可以直接打开导航。外观中的主题可明确选择浅色、深色或跟随系统，改动即时生效。

AI 详情在窄窗打开时，`Ctrl+Shift+F` 会回到内容列表并聚焦搜索，未完成的草稿保留在侧栏“正在编辑”。AI 与扩展无搜索结果时可点击“清除筛选”；插件市场的搜索与类型筛选固定在列表顶部。

| 快捷键           | 操作                         |
| ---------------- | ---------------------------- |
| Ctrl+O           | 打开文件                     |
| Ctrl+Shift+O     | 添加阅读库                   |
| Ctrl+P           | 快速打开                     |
| Ctrl+E           | 阅读 / 编辑                  |
| Ctrl+S           | 保存                         |
| Ctrl+F           | 当前文档查找                 |
| Ctrl+Z / Ctrl+Y  | 撤销 / 重做                  |
| Ctrl+Shift+B     | 左侧阅读库开关               |
| Ctrl+Shift+R     | 右侧上下文开关               |
| Ctrl+Shift+Enter | 专注模式                     |
| Esc              | 退出当前菜单、弹层或专注模式 |

## 按需添加阅读工具

打开「插件市场」，选择安装待办提取、链接清单、表格导出或文档体检。打开 Markdown 文档后，从插件详情直接运行，或进入「更多操作 → 阅读插件」。点击结果条目可回到原文；报告可复制或保存，表格可单独导出 CSV。这些工具本地运行，不修改原文、不调用 API。

需要 AI 帮助分析论证或主动回忆时，可安装「论证审阅」或「复习教练」，沿用自己的 API 服务。只有明确附加的普通文档会发给服务。完整能力和边界见 [扩展指南](EXTENSIONS.md)。

## 数据在哪里

文档始终留在你选择的位置。最近记录主要保存路径与会话信息，草稿会包含未保存正文，设置保存在本机。使用读取授权后的本地附件，不为方便显示而授予任意磁盘访问权限。浏览器存储与桌面存储独立，清除浏览器数据会影响预览环境中的设置和草稿。

AI 空间可见时每 12 秒轻量核对一次数据库变化；资料未改变时不重复检索。通过 MCP 修改、记忆到期或回到窗口时会重新核对。切到其他空间或隐藏窗口后暂停该检查；失败保留已有结果并显示重试提示。
