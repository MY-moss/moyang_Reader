# v0.9 及更早交接摘要

本文件只保留后续维护仍需要的历史约束。精确记录可从 Git 历史、Release 和旧版 `docs/AI-HANDOFF.md` 追溯。

## v0.9

- 建立 Windows x64 三栏阅读工作区、多阅读库、WYSIWYG 默认编辑入口和无控制台桌面启动。
- 固化 Markdown 真源、无法安全往返时回退源码、统一渲染链负责阅读/搜索/导出。
- 完成编辑历史、阅读位置、模态焦点、草稿恢复、外部修改保护和真实 Windows Tauri smoke 基线。
- 发布工作流形成 GitHub Release、NSIS、`.sig`、`latest.json` 和 Cloudflare 镜像验证链路。

## v0.8 及更早

- 建立 Tauri 2 + React/TypeScript/Rust 本地阅读器骨架。
- 支持 Markdown、文本、DOCX、PDF、图片、文件夹工作区、全文搜索和基础导出。
- 明确本地优先、无账号/云数据库、路径和阅读偏好只保存在本机。
- 平台范围收敛到 Windows x64；浏览器版只用于本地预览和 Playwright 测试。

## 长期不变量

- Markdown 文本是唯一持久化真源。
- Rust/Tauri 是路径授权、文件读取和安全写入边界。
- 用户文档正文默认不上传；远程图片和自动更新检查由本机偏好控制。
- 功能切片一次只处理一个主题，测试、文档和交接随同一 PR 提交。
