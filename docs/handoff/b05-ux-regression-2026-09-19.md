# B05 — 当前主流程 UX 回归

## 复现

- 窗口宽度：960px，打开一个 Markdown 文档并进入阅读模式。
- 打开右侧“文档上下文”面板。
- 结果：`<=1180px` 的响应式规则会把上下文面板绝对定位到中央内容上方；原实现没有遮罩，编辑器/正文被无提示覆盖，也没有统一的 Esc 取消路径。

## 修复

- 窄窗口上下文面板增加位于正文之上的遮罩，明确当前是抽屉状态并阻止误触下方内容。
- 点击遮罩关闭面板。
- 在没有更内层弹层消费 Esc 时，Esc 关闭窄窗口上下文抽屉。
- 关闭仍复用原有 `contextPanelRestoreFocusRef`，恢复打开面板前的触发按钮、编辑器或正文焦点。

## 验证

- `npm test -- --run`：103 个测试文件、448 个测试通过。
- `npm run lint`：通过。
- `npm run build`：通过。
- `npm run format:check`：通过。
- 新增 Playwright 场景：960px 抽屉遮罩可见、面板层级高于遮罩、遮罩关闭和 Esc 关闭均归还上下文按钮焦点。

## 边界

- 宽窗口仍保留并排上下文面板，不把 Esc 改成全局关闭右侧面板。
- 本次只处理窄窗口面板的交互反馈和取消路径，不修改索引算法、拼音匹配、IPC 或 Rust 文件行为。
