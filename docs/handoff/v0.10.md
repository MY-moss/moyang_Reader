# v0.10 交接摘要

本文件归纳 v0.10 的稳定版本与关键切片。精确提交、测试数字和讨论以 Git 历史、Release、PR 与对应 Issue 为准。

## 稳定版本

- v0.10.1：5000 文档搜索性能与撤回/重做阅读位置修复。

- v0.10.4–v0.10.10：工作区文件管理、右键操作、标签页管理、阅读缩放和工作区内转移。
- v0.10.11–v0.10.12：性能修复、大工作区枚举边界、文件树虚拟化和 PDF 后台落盘稳定性。
- v0.10.13：草稿差异预览、原生编辑工具栏、窄窗口完善及相关稳定性切片。
- v0.10.14：批量 DOCX 导出刷盘和 Worker 部分失败恢复修复，作为独立小版本发布。

## 核心交付

- 三栏、多阅读库、全文搜索、快速打开、多标签和目录/关联/属性上下文面板。
- Markdown WYSIWYG/源码编辑、双链与 slash 补全、草稿恢复和外部修改保护。
- 工作区文件/文件夹 CRUD、复制/剪切/粘贴、属性、路径和右键管理。
- HTML、DOCX 与打印/PDF 单篇和批量导出，含取消、分卷、失败清单和临时文件原子提交。
- Windows 单实例、文件关联、原生拖放、更新器、真实 Tauri desktop smoke。
- 大工作区有界扫描、文件树虚拟化、阅读轨道和文内搜索性能优化。
