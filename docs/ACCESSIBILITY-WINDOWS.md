# Windows 可访问性手动冒烟清单

本清单用于补充 axe 自动扫描。它验证 Moyang Reader 在 Windows x64、键盘和屏幕阅读器环境下的核心路径，不把自动化结果描述成完整的读屏认证。

## 执行边界

- 发布前至少抽查一次；涉及焦点、弹层、快捷键、主题或保存流程的 PR 合并前抽查受影响路径。
- 自动化 axe 负责发现 DOM 语义、名称、关系和 critical/serious 规则问题；本清单负责真实键盘顺序、焦点位置、读屏播报和高对比度体验。
- 发现问题时记录最短复现路径、Windows 版本、读屏软件和对应 Issue，不在清单中掩盖或静默豁免。

## 固定环境

- 系统：Windows 10 或 Windows 11 x64，记录具体版本和显示缩放比例。
- 读屏：Windows Narrator；条件允许时再用最新 NVDA 复核。
- 输入：键盘为主，鼠标只用于确认鼠标操作没有破坏焦点。
- 语言：中文界面为主；切换英文时抽查标签没有截断或失去语义。
- 主题：浅色、深色、系统主题和 Windows 高对比度；另外抽查“减少动画”。

## 核心路径

按顺序执行与当前版本相关的路径，并在每条路径结束后确认焦点没有落到不可见元素。

### 1. 空状态与启动

- 启动应用，使用 `Tab`/`Shift+Tab` 浏览“打开文档”“添加整个文件夹”“使用教程”等入口。
- 使用读屏确认窗口、主标题、按钮名称和支持格式说明可被理解。
- 触发一次打开失败或取消，确认错误/取消状态被播报，焦点仍在可操作控件。

### 2. 阅读库与文件树

- 使用 `Ctrl+Shift+O` 添加一个测试文件夹；在文件树中用方向键、`Enter` 和 `Shift+F10` 操作。
- 展开/折叠文件夹，打开 Markdown、TXT 和一个只读格式，确认当前项、文件类型和路径播报清楚。
- 打开文件右键菜单，使用 `Tab`、`Shift+Tab`、方向键、`Home`、`End` 和 `Escape`；关闭后焦点回到触发项。
- 删除或重命名测试条目前先取消确认，确认文件树和当前文档没有意外变化。

### 3. 阅读区与上下文面板

- 用 `Ctrl+Shift+R` 打开/关闭右侧上下文面板；确认焦点、按钮名称和当前文档没有被改变。
- 在目录中选择标题，确认正文滚动到对应标题；在关联、属性和关系图入口中确认目标文档明确。
- 使用 `Ctrl+Shift+Enter` 进入和退出专注模式，确认左右面板隐藏后仍能返回。

### 4. 快速打开与命令面板

- 使用 `Ctrl+P` 打开快速打开，确认焦点进入搜索框；用上下键选择、`Enter` 打开、`Escape` 关闭。
- 使用 `Ctrl+Shift+P` 打开命令面板，确认结果、当前项和关闭后的焦点稳定。
- 在没有匹配项时确认空状态说明下一步，而不是只播报空白列表。

### 5. 编辑与保存

- 使用 `Ctrl+E` 进入 Markdown 编辑；用 `Ctrl+S` 保存，确认“保存中/已保存/保存失败”状态可读。
- 抽查 `Ctrl+Z`、`Ctrl+Y`、工具栏、段落样式、链接/图片/表格插入和源码模式；编辑器焦点与选区不被工具栏抢走。
- 模拟外部修改和关闭未保存文档，确认冲突/保护弹层支持 `Tab` 循环、`Escape` 和焦点归还。

### 6. 设置、教程与导出

- 打开设置和首次使用教程，确认弹层有标题、初始焦点、`Tab` 循环和关闭后的焦点归还。
- 修改一个设置并重新打开，确认“正在保存/已保存到本机/备用存储/保存失败”状态准确。
- 打开导出或打印预览，确认进度、取消、失败清单和完成状态可被读屏获取。

### 7. 主题与动效

- 在浅色、深色和系统主题下重复检查正文、辅助文字、链接、错误和状态提示的可读性。
- 开启 Windows 高对比度，确认边界、焦点环、按钮和正文仍可辨识，axe 检查不出现新的 critical/serious 违规。
- 开启“减少动画”或系统减少动画设置，确认面板、菜单和加载状态不会快速闪烁或阻断操作。

## 记录模板

| 日期       | 版本/提交    | Windows | 读屏与版本    | 缩放/主题   | 结果      | Issue    |
| ---------- | ------------ | ------- | ------------- | ----------- | --------- | -------- |
| YYYY-MM-DD | vX.Y.Z / SHA | 11 x64  | Narrator/NVDA | 100% / 浅色 | 通过/失败 | #id 或无 |

失败记录至少包含：场景编号、实际焦点或播报、预期结果、最短复现步骤和截图/录屏路径。自动 axe 结果应同时记录扫描入口和 `run_id`，不要只写“无障碍通过”。
