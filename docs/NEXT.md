## 唯一下一步：#119 axe/WCAG AA Windows UI 基线

- Issue：[在线查看 #119](https://github.com/MY-moss/moyang_Reader/issues/119)
- 优先级：Should / P3
- 风险级别：T2（浏览器扫描、主题对比度和 Windows 键盘/读屏清单）
- 版本分类：不单独发布；验收结果进入 `v0.11.0`

### 用户价值

把核心 Windows UI 的可访问性从人工检查变成可重复的质量基线，并让后续视觉/键盘改动有清晰的回归证据。

### 本切片范围

- 在浏览器 E2E 的空状态、阅读、快速打开和设置入口运行 axe 扫描。
- 将 critical/serious 违规作为质量门禁；确有上下文误报时记录最小、可追溯的豁免。
- 对浅色、深色和高对比度主题的关键文字/背景组合做 WCAG AA 对比度检查。
- 记录 Windows Narrator/NVDA 的核心键盘和读屏手动冒烟路径，不声称自动化工具替代真实读屏。

### 非目标

- 不把 minor 视觉建议全部变成阻塞 CI。
- 不在本切片重写全部弹层、重构主题令牌或修改文档内容。
- 不承诺完整 NVDA 认证，不引入云端服务或新的运行时依赖。

### 验收标准

- [ ] 空状态、阅读、快速打开和设置四类入口的 axe 扫描可在 CI 重复运行。
- [ ] critical/serious 违规为零，或每个豁免均有原因、定位和后续处理记录。
- [ ] 浅色、深色和高对比度的关键颜色组合有可追溯 WCAG AA 计算结果。
- [ ] Windows 键盘/读屏手动清单覆盖打开、关闭、焦点、错误和核心操作，并记录实际抽查结果。
- [ ] 相关 lint、format、定向 E2E 和 Quality checks 全绿。

### 依赖、风险与回滚

- 依赖：现有 Playwright、主题令牌、#191 键盘语义和已完成的 #299 焦点契约。
- 风险：axe 可能产生上下文相关误报；扫描入口和豁免必须固定并记录原因。
- 回滚：扫描先降级为非阻塞报告，但保留基线、结果和手动清单，不删除质量证据。
