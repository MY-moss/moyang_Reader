## 唯一下一步：#299 右键菜单焦点循环、关闭归还与稳定导航

- Issue：[在线查看 #299](https://github.com/MY-moss/moyang_Reader/issues/299)
- 优先级：Should / P3
- 风险级别：T2（共享右键菜单、键盘焦点、四类入口和 Windows UI 回归）
- 版本分类：不单独发布；验收结果进入 `v0.11.0`

### 用户价值

让键盘和读屏用户在文件树、标签页、阅读区和编辑器右键菜单中始终知道焦点在哪里，并能连续完成操作。

### 本切片范围

- 在共享右键菜单中拦截 Tab/Shift+Tab，按统一菜单契约循环或关闭，不让焦点逃逸到背景。
- 打开菜单时记录触发元素；Escape、菜单项选择和外点关闭后，在触发元素仍连接时归还焦点。
- 复用现有方向键、Home/End、首项聚焦和视口钳位行为，避免父组件重渲染重置高亮。
- 覆盖文件树、标签页、阅读区和编辑器四类入口，并补共享行为测试与一条键盘 E2E。

### 非目标

- 不改变现有鼠标菜单项、业务动作或快捷键。
- 不在本切片重写全部弹层，不引入新的菜单库。
- 不修改 Markdown、TXT、DOCX、PDF、文件树 CRUD、更新器或发布资产。

### 验收标准

- [ ] Tab/Shift+Tab 不会把焦点留在已打开菜单之外，菜单循环行为有单测。
- [ ] Escape、点击菜单项和外点关闭后焦点归还到可用触发元素；触发元素失效时聚焦安全容器。
- [ ] Arrow/Home/End 导航、首项聚焦和菜单视口钳位不回归。
- [ ] 文件树、标签页、阅读区和编辑器至少覆盖一条键盘 E2E，读屏状态保持可理解。
- [ ] 相关 lint、format、build、单测、浏览器 E2E、Windows desktop smoke 和 Quality checks 全绿。

### 依赖、风险与回滚

- 依赖：#191 键盘/读屏导航边界，以及现有 `useModalBehavior` 和右键菜单实现。
- 风险：触发元素可能在关闭前被删除或移动；归还前检查 `isConnected`，失败时聚焦安全容器。
- 回滚：回退单一 #299 PR 的共享焦点层，不回退既有菜单项和业务动作。
