## 唯一下一步：#369 回收站删除与保存上一版本保护

- 优先级：Should / P2
- 风险级别：T3（删除语义、保存安全和 Windows 原生文件系统）
- 计划版本：v0.11.x
- Issue：[#369](https://github.com/MY-moss/moyang_Reader/issues/369)

### 用户价值

误删文件或文件夹可以从 Windows 回收站找回；误覆盖保存可以恢复上一版本，降低编辑风险。

### 本切片范围

- 删除文件和文件夹改为 Windows 回收站语义；回收站失败时明确提示并保留永久删除边界。
- 保存成功后保留最近一份 `.moyang.bak`，滚动覆盖上一版本。
- 增加“恢复上次保存版本”入口，复用现有草稿差异预览和未保存保护。
- 评估 Windows 原生实现与 Rust 依赖的体积、审计和错误处理，不引入多级历史。

### 非目标

- 不做多级版本历史、定时快照、独立回收站 UI、云同步或跨平台支持。
- 不改变现有删除前确认契约，不迁移用户已有文件。
- 不顺手扩展编辑器、导出、更新器或其他 Issue。

### 验收标准

- 删除文件/文件夹后可在 Windows 回收站找到并还原；回收站失败有明确结果。
- 连续两次保存后 `.moyang.bak` 内容等于上一版本；恢复动作先进入编辑区，显式保存后才写回。
- 删除确认、watcher 刷新、递归目录、外部修改和未保存保护不回归。
- Rust 定向测试覆盖 bak 滚动、恢复和失败边界；Windows desktop smoke 覆盖删除与恢复路径。
- 发布/更新/签名改动才执行完整发布门禁；本切片完成后再决定是否纳入 `v0.11.0` 安装包。

### 依赖、风险与回滚

- 依赖：Windows 回收站 API、现有删除确认与保存链路、草稿差异预览。
- 风险：回收站对网络盘/特殊路径不可用；bak 常驻会增加空间占用，大文件策略必须明确提示。
- 回滚：回退本切片 PR，恢复原删除和备份清理逻辑；不删除用户文件，不需要数据迁移。

### 预计修改范围

- 代码：`src-tauri/src/commands.rs`、保存/恢复相关前端边界及必要的 Windows API 封装。
- 测试：Rust 定向测试、相关前端测试、一个 Windows desktop smoke。
- 文档：`docs/NEXT.md`、`docs/AI-HANDOFF.md`、`docs/ROADMAP.md`、`CHANGELOG.md`。
