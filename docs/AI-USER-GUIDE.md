# AI 空间使用指南

左侧空间切换器选择“AI 空间”。日常笔记与 AI 数据独立，只有你明确导入的内容进入 AI 库，外部 Agent 不会自动扫描阅读空间。

## 内容与编辑

知识库存资料与解释；长期记忆存明确偏好、事实、决定和经验；技能库存使用场景、步骤、参考资料与资源。

新建后填写标题和正文。正文默认直接编辑，选中文字可格式化，输入 `/` 插入常用结构；需要保留复杂 Markdown 时切换源码。属性默认折叠。停止输入约 1.2 秒后保存，中文组词期间暂停；Ctrl+S 立即保存。多个草稿可从侧栏切换，重启后仍可恢复。保存期间可继续输入。与其他 Agent 同时修改时提供差异比较、合并和另存副本。

新记录可选全局共享或项目共享；Agent 字段记录来源。旧记录保持原项目及 Agent 范围，迁移不会自动扩大共享。有效期结束后正文保留，默认不召回；“含过期”可找到它。归档可恢复，永久删除会删除历史。

## 导入与来源更新

支持 MD、TXT、DOCX、文字型 PDF 和网页正文。导入生成独立快照，保存来源、导入时间和内容指纹。网页正文经 Readability 提取；需登录或复杂脚本的网页可粘贴正文或导入已保存文件。扫描 PDF 没有 OCR，无法提取时明确提示。

打开来源区可定位原文件、段落或物理页。原资料变化后选择“检查更新”，查看差异，再决定是否替换快照；已有正文不会被后台覆盖。

资料较多时，进入 **近期活动与冲突 → 来源更新**，选择项目后点击“检查全部来源”。列表区分来源变化、没有变化、无法读取和需重新选文件，可停止检查或只重试失败项。网页检查会访问原网站，文件在本机读取；整个检查不调用模型。

点击“查看差异”会重新读取这一个来源，比较当前快照与最新正文，再决定是否更新。更新保留标题、标签、范围与关联，旧正文仍在历史中；其他 Agent 同时修改时会阻止过期覆盖，可点击“重新读取与比较”。空正文、失效路径和不可访问网页不会清空现有资料。浏览器仅保存文件名时，需要重新选择原文件。

批量结果只保留来源信息与本次检查状态，不长期缓存每篇新正文；离开来源更新页后需重新检查。普通笔记、手动记忆和技能不进入这个检查队列。

技能可导入单个 SKILL.md、技能目录或 ZIP，保留 references、scripts、assets 和扩展元数据。名称遵循小写字母、数字和短横线规则。资源可单独预览、替换、移除与下载；文本、图片和 PDF 有内置预览，其他格式可下载后打开。应用不会执行技能里的脚本。

关联内容按名称搜索选择。点击关联可在侧边预览，不丢弃当前文档或草稿。历史中可比较正文差异并恢复旧版本，恢复会产生新版本。

历史按页展示，展开某一版本才读取正文。技能资源的新增、移除、修改单独列出；展开后比较当时资源与当前资源，即使名称和大小都没有变也能发现内容变化。资源读取期间会提示进度并暂停保存；放弃或离开这份草稿会取消尚未完成的导入。

## 检索与本地模型

Agent 的 `recall_context` 会在给定字数预算内为多条相关资料分配空间，压缩冗长标题和来源，并围绕查询词保留证据窗口。每条结果标出项目范围，截短处显示省略号；需要完整依据时按 ID 读取原记录。技能只返回摘要，附件仍按需读取。这不增加模型或重排服务。

搜索先显示关键词命中，再补充语义结果，最多显示四个来源片段。项目筛选限制项目内容，全局偏好可随任务共享；旧 Agent 私有范围仍保留。

桌面“接入与备份”可准备 `qwen3-embedding:0.6b`，模型文件约 639 MB。便携包的 ollama 目录包含本地运行程序和已下载模型；首次准备或运行已有 Ollama 时需要等待服务就绪。启用后自动补齐新增或变化正文的向量，改标题、标签不重复嵌入。手动“建立 / 补齐索引”可以查看进度。

多个 Agent 同时连接也不会重复计算同一批索引。暂停会对本库所有客户端生效，当前批完成后停止；再次点击建立索引继续。导入期间，当前范围尚未索引完整时先显示完整关键词结果，并提示等待索引；完成后恢复语义补充。

本机地址 `127.0.0.1:11434` 保持本地处理；若你改为远程服务，会将相应查询和索引正文发送到该地址。服务失败保留关键词结果。真实中文回归结果和性能见 [中文检索实测](VALIDATION-AI-SEARCH.md)。

## 资料检查

进入 **AI 空间 → 近期活动与冲突 → 资料检查**。选择项目、类型和 Agent，可以集中查看：

- **正文相同**：同类型、同项目、同共享范围内的相同正文；忽略换行格式和首尾空白，保留缩进、标点差异。旧 Agent 私有内容不与其他 Agent 自动归为一组。
- **已到期**：仍保存但默认不参与召回的内容。查看后可编辑有效期或归档。
- **未填写来源**：来源字段和快照地址都为空。它是补充出处的提醒，不代表内容错误。
- **关联已删除**：引用的条目已不存在。归档条目仍可读取，不算失效关联。

检查按需在本机执行，不调用模型，不扫描普通笔记；每页 30 条。正文相同不代表来源、附件或用途相同，展开可查看其他候选，然后选择“查看与整理”。归档保留历史，刚归档的条目可以撤销，也可以之后从归档列表恢复。没有自动删除或合并操作。

“全部项目”检查整个 AI 库，“仅全局”只检查全局内容。选择具体项目时，默认不混入全局；可勾选“包含全局资料”。Agent 筛选保留共享条目，只限制旧私有范围。结果标出检查时间；其他客户端修改后可点“重新检查”。

## 连接 Codex 与 Claude Code

1. 桌面进入“AI 空间 → 接入与备份”，为客户端点击“连接并开启自动沉淀”。应用精确合并已有配置，并在原文件旁创建备份。
2. 重新连接客户端。Codex 在 `/hooks` 中检查并信任 Moyang 四项钩子；若客户端要求 MCP 写入授权，也在客户端完成。应用不跳过客户端信任。
3. 开始一次任务，例如：“请记住我喜欢简洁中文，并在下一次回答时使用。”检查接入页是否出现 MCP 连接、钩子运行和成功完成记录。
4. 在近期活动中查看保存原因、来源及旧版本，可撤回和恢复。若没有值得保存的新信息，Agent 可以完成检查点而不新增记忆。

支持当前本机 Codex 桌面端/CLI 和 Claude Code 2.1.300 的生命周期格式。其他客户端复制通用 MCP 配置，并加入页面提供的使用约定；结束时自动处理是否可用，取决于该客户端是否支持钩子。

界面分别显示配置、实际 MCP 初始化、钩子回执和最近成功沉淀。配置成功不代表模型服务可用，也不代表客户端已批准钩子。移除连接只删除本应用写入的部分；遇到用户后来修改的同名配置会保留并提示。

MCP 由客户端启动，无需一直打开阅读器。Agent 使用原始任务检查点，重复回调不会重复写入；结束时最多补充一次。明确更正替代旧规则且保留历史，推测的矛盾进入待处理列表；技能改善必须附任务证据和成功/失败结果。中断任务会在后续恢复时提示，不伪造完成状态。

这会改善 Agent 可用的上下文与方法，不会训练外部模型权重。

## 备份与恢复

“导出完整备份”保存记录、资源、历史、有用/无用反馈及反馈次数、检查点、冲突、活动和可迁移设置。导入按 ID 合并，已有记录及其反馈不覆盖；空库导入可完整恢复内容、历史和学习反馈。旧备份缺少反馈时仍可导入。连接所有权及回执属于本机，迁移后需重新连接客户端。向量可从正文重新建立。

AI 库还自动保留 7 个日快照、4 个周快照，数据库升级前另做完整快照。需整体回退时退出阅读器及使用本库的所有 Agent，先备份现目录，再按 [迁移与恢复手册](MIGRATION.md)替换。不要在运行时只复制 SQLite 主文件而遗漏 WAL。
