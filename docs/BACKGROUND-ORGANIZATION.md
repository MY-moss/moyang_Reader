# AI 服务、限额整理与模型选择

本轮开发版功能；整体发布验收仍在进行。

## 服务和额度

“设置 → AI 服务与整理”独立于聊天插件。现有服务 ID、协议与密钥沿用原存储，聊天、整理和嵌入分别选择服务及模型。密钥不进入知识备份；在普通备份恢复后需重新配置服务和启用整理。

首次启用必须选择服务、模型与每日 token 额度。预留包括输入估算和输出上限；响应提供实际用量时结算，缺用量、失败或中断保留估算标记。重试计入额度。额度按 UTC 日重置，界面显示本地重置时间；不估算货币费用。嵌入 API 和手动聊天不占此整理额度，按各自服务计费。

桌面或 MCP 任一运行时可消费共享队列；操作系统文件锁保证同库同时只执行一个整理请求，无额外常驻服务。两者关闭后队列保留。新增和变化内容优先，原文指纹相同不重复排队；提交前检查原修订与当前配置。暂停时不提交正在完成的旧结果，其请求仍计用量。取消待处理任务不删除原文。失败最多自动尝试三次，随后可手动重试。

同义合并只处理相同范围、有效期和记忆类型的长期记忆。模型必须明确判断含义和适用条件一致，数字、版本和否定等约束另外核对。不确定提议在“近期活动 → 记忆整理与合并”展开比较，手动选择合并或分别保留。成功后新记忆关联原记录及来源，原文归档；整组撤回验证全部版本。若结果已编辑，先查看后续变化，不覆盖新内容。

## 本地模型与嵌入 API

“AI 空间 → 接入与备份 → 语义检索”提供本地模型目录与下载。先选目录、选择规格，再下载；可取消、继续下载、选择此目录已安装的模型。下载完成后点击“使用所选模型”，然后按需建立索引。

预设 Qwen3 Embedding 0.6B（约 639 MB）、4B（约 2.5 GB）、8B（约 4.7 GB），也支持自填其他 Ollama 嵌入模型名称。以上为官方目录的下载体积，不等于运行内存或质量保证；大模型适合资源充足的设备。[官方模型目录](https://ollama.com/library/qwen3-embedding)。

本应用管理的运行程序使用 127.0.0.1:11435，通过 OLLAMA_MODELS 指向选定目录。独立安装的 Ollama 配置保持原样。应用保存运行进程身份，重启后停止服务时核对同一进程。未找到运行程序时提供官方安装入口。已有模型可在存储页迁移，直接更改下载目录不擅自删除或移动原文件。

“嵌入方式 → 我的嵌入 API”使用共享服务中的 OpenAI 兼容接口，模型名称独立填写。密钥只从服务存储读取；接口使用 embeddings 响应的 index 恢复顺序并校验维度。修改服务地址后需重新保存检索配置，避免把新密钥发到旧地址。切换模型或协议不会混用旧向量，索引未齐时使用完整关键词结果。

## 分项存储

“设置 → 存储位置”可单独选择 AI 库、自动快照、API 与聊天、扩展、界面数据、模型及应用更新版本目录；也可整体迁移应用数据。文档仍在用户原来的文件夹，手动导出时可单独选择文件位置。Windows 系统临时目录由系统管理，不伪装为本应用设置。

迁移使用所选文件夹中的 MoyangData 子目录，检查后保存并退出、复制校验、建立原路径链接再重新打开。父目录迁移保留此前分开的目录链接，清理旧副本不会遍历链接删除独立数据。更新版本目录包含可启动的程序版本，迁移时保留原路径以支持现有快捷方式和更新指针。
