# 0.18 使用与架构说明

## 使用入口

设置 → AI 服务与整理，按“先选磁盘、按用途选择、按需启用”完成配置。可直接跳转存储位置，管理共享 API，或展开本地模型与嵌入 API 设置。接入与备份页面复用同一检索设置组件。

公开轻量 ZIP 不包含 Ollama 运行程序和模型。未安装时，模型面板提供官方安装入口；已有运行程序可直接使用。选择模型保存目录后，再选择 0.6B、4B、8B 或填写其他嵌入模型下载。也可完全使用自己的嵌入 API。应用不自动下载大模型。

“测试嵌入连接”仅发送一条固定中文短句，检查有效向量及维度，不改变当前配置或索引、不发送库内资料。可停止，30 秒后自动取消；外部 API 可能产生少量用量。通过后保存设置、建立索引。模型下载状态串行检查，隐藏窗口时暂停，恢复窗口时继续。

## 书房聊天

- 一个服务保存多个模型；本次模型与新对话默认模型分开。模型较多时可以搜索，点星标保存常用模型。
- API 服务 → “预算与测试的模型”选择要设置的模型，不改变默认模型。展开预算选项，填写上下文上限、回答输出上限及输出参数。
- 未配置时采用 16384 上下文、4096 输出的规划预算。这是默认起点，不声称所有模型支持此容量。按服务文档调整；输入按 UTF-8 字节 / 2 估算，再预留 10% 余量。估算不等于实际计费或精确分词。
- 超出预算时省略最早的完整消息；当前问题和附加资料过长时提示调整，不静默截断。完整历史仍保留在本机。
- OpenAI 兼容接口默认请求流式用量。服务以 400 / 422 明确拒绝 `stream_options` 时，去掉该选项重试一次；超时、额度、其他错误不自动重发。也可手动关闭流式用量选项。
- 服务返回完整用量时显示实际报告；缺失、空报告或只有不完整计数时保留估算标记，用量随消息保存。中断时收到的用量可能只是服务已报告的部分。
- 测试状态只表示该模型最近一次通过文字回答测试，不推断模型目录中的条目都支持聊天、图片、工具或嵌入。修改服务地址、协议或密钥后清除旧测试标记。
- 长会话默认只挂载最近 40 条消息；“加载更早的消息”每次增加 40 条。Markdown 正文组件复用未变化的渲染结果；导出仍包含完整会话。

## Agent 条件读取

`read_context` 的 L0/L1 是原文的派生视图。后台概览变化不应伪造一次正文修订，因此不能仅依据 `revision` 判断这两层未变化。

所有正文层返回 `etag`，覆盖当前可读内容与状态、范围、概览状态等元数据。客户端传入 `if_etag`，一致时返回 `unchanged: true` 和紧凑元数据。正文、概览、到期、状态或范围变化都会重新返回内容。连续读取仍使用 `expected_fingerprint` 防止新旧片段混接。

旧 `if_revision` 保留在 L2；L0/L1 的旧请求仍可调用，但返回精简正文，不错误省略新概览。L3 未指定修订时仍先返回历史清单。

```json
{ "items": [{ "id": "record-id", "layer": "l1", "if_etag": "上次返回的 etag" }], "max_chars": 2000 }
```

## 部分索引与缓存

当当前范围尚有缺少向量或维度不匹配的片段时，先保持完整关键词顺序与分页，再追加已就绪且不属于关键词匹配的语义结果。界面显示索引正在补齐。相同关键词表达式用于搜索与去重，避免长查询分页重复。模型不可用时继续返回关键词结果与原因。

解析过的向量按“模型标识 + 完整向量字节”缓存，缓存最多约 16 MiB（含条目预算）。正文修改、跨进程写入、模型切换和备份恢复无法命中内容不同的旧向量；本地历史不会因为命中过期标识而串库。此优化减少重复 JSON 解析，不改变数据库，不引入额外模型或向量服务。扫描和相似度计算仍是线性的，不宣称超大库恒定耗时。

## PDF 导出

Windows 导出在工作线程运行，右下角显示状态及取消入口。渲染器最多运行 60 秒；取消或超时停止本次创建的渲染进程，清理临时文件。有效 PDF 生成后才原子替换目标，失败不覆盖已有文件。关闭应用时等待当前导出完成或取消。

## 兼容与验证边界

无数据库结构升级。共享服务新增可选字段，旧服务、聊天历史、普通笔记和备份接口继续可读。升级保留已有存储位置与模型，普通知识备份不包含 API 密钥。

测试使用正常短对话、46 条会话、现有检索夹具和既有回归。真实 Codex / Claude Code 任务结束自动沉淀仍按用户此前暂缓的客户端授权与模型服务条件验收；应用和协议测试不替代个人客户端授权。
