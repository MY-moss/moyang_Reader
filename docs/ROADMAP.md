# Moyang Reader 产品路线

路线图只描述产品阶段；当前可执行小任务统一维护在 [`AI-TASKS.md`](AI-TASKS.md)，稳定发布事实见 `release-status.json`。

## 产品完成态

v1.0 是可靠、离线、本地优先的 Windows x64 阅读工作台。文件安全、打开、阅读、编辑、搜索、关联、导出、恢复和更新构成稳定闭环。

核心方向不是继续堆功能，而是形成四个优势：

1. **轻量**：启动、打开、搜索、切换尽量快，大工作区和大文件有明确降级策略。
2. **本地真源**：Markdown/frontmatter/普通文件仍能被其他工具直接读取，不把内容锁进私有数据库。
3. **顺手**：高频动作容易发现，鼠标/键盘路径一致，状态、错误和取消结果可预测。
4. **AI 友好维护**：代码按职责拆分、测试边界清楚、任务足够小，让不同 AI 可以连续接手。

## 当前已形成的产品基线

以下能力已经完成，后续按回归基线维护，不再作为“未来功能”重复规划：

- 文档跳转历史与返回上一文档。
- 文档书签、选中文本高亮/批注。
- 删除进入系统回收站与上一保存版本恢复。
- 最近阅读、阅读时长/本周统计。
- 中文文件名拼音首字母快速打开/搜索。
- 阅读位置随设置备份迁移。
- 基础键盘导航、axe/WCAG AA、reduced-motion、浅色/深色/高对比度测试。

## v0.11：契约、结构与桌面体验收口

- 完成 TS ↔ Tauri 命令契约集中化和首批运行时响应校验。
- 渐进拆分 `App.tsx`：先设置/偏好，再文档会话；Rust 命令按领域逐步拆分。
- 明确“快速打开 / 文内查找 / 阅读库搜索”三类入口，减少搜索语义混淆。
- 把命令面板做成真正可用的键盘入口：活动项语义、滚动、快捷动作和 enable 状态统一。
- 收口右侧上下文页签的键盘与 ARIA 行为。
- 审查顶栏/More/设置/导出菜单的信息层级，优先保证高频动作可见和状态清楚。
- 验证 Windows 100% / 125% / 150% / 200% 缩放以及 720/900/1240px 关键宽度下的可读性、截断和溢出。
- 继续收敛 CSS 令牌，并只为少量关键状态建立稳定视觉回归截图。

目标不是追求某个文件行数或“更现代的 UI”，而是让用户更快完成常用动作，同时让每次交互修改只需要理解一个较小职责边界。

## v0.12：稳定性、性能与真实使用回归

- 建立 5k/20k 文件工作区的可重复扫描/搜索 benchmark。
- 测量 1MB/10MB Markdown 首次可读、编辑、搜索、保存和内存占用。
- 大文件超过安全阈值时明确降级，而不是卡死或静默失败。
- 对当前 `main` 走一遍真实主流程：首次启动、阅读库、定位、阅读、搜索、跳转、书签/批注、编辑、保存、外部修改、恢复、导出。
- 只把能在当前代码复现且明显影响用户的 UX 问题拆成 0.5–3 天小任务，不重复审计已关闭问题。
- 对 Tauri opener/process/updater 做权限库存与负向测试；先证明问题，再收权限。

## v0.13：轻量知识库增强

已有的导航、书签、批注和阅读统计继续保持轻量。本阶段只补真正缺失、且不会锁定用户数据的能力：

- Inbox：一键把普通 Markdown 写到用户指定目录。
- Daily Note：按本地日期创建/打开普通 Markdown，保持简单模板。
- 将当前只读的 YAML frontmatter 属性面板扩展为安全的常见字段编辑。
- 在索引之上提供轻量属性/标签表格视图，Markdown 仍是真源。

不复制 Notion/Obsidian 的全部功能；只吸收对本地阅读工作台真正高价值的部分。

## v0.14：AI 与扩展接缝

- 稳定内部 `DocumentAdapter` / `IndexProvider` 边界。
- 建立 `CommandContribution`，逐步统一命令面板、快捷键和顶部动作的 enable/label/shortcut 来源。
- 建立 `AiProvider` 与 `ConsentScope`，先使用 mock/本地 provider 验证边界。
- 核心默认不联网；发送内容时展示范围、用途和 provider；写回提供差异预览。
- 不加载任意脚本、iframe/WebView 插件，不承诺第三方 ABI。

## v0.15：冻结与兼容

- 冻结设置 key、IPC 命令、核心快捷键和主要保存行为。
- 覆盖损坏设置、异常退出、磁盘满、只读文件、外部删除/修改和大文件降级。
- 验证升级、重装、旧配置和旧版本数据兼容。
- 关闭所有高严重度缺陷；其余延期必须有明确理由。

## v1.0：发布出口

- Windows x64 安装、卸载、升级、恢复和自动更新完整验证。
- Release、安装包、updater `.sig`、`latest.json`、镜像和 SHA-256 一致。
- 有 Authenticode 证书则完成签名；没有时明确披露，不把 updater 签名描述成 Windows 代码签名。
- 完整前端、Rust、浏览器、真实桌面、安全和恢复矩阵通过。

## 长期边界

v1.0 前暂不投入：账号、云同步、实时协作、移动端、macOS/Linux/Windows ARM 安装包、第三方任意脚本插件、DOCX/PDF 原格式回写、常驻后台服务或捆绑本地大模型。
