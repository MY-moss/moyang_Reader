# Moyang Reader 产品路线

路线图只描述产品阶段。可执行队列由受保护的 `ai/plan-v1.json` 决定，运行状态由 `ai/state.json` 决定，发布事实见 `release-status.json`。

## 产品完成态

v1.0 是可靠、离线、本地优先的 Windows 阅读工作台。Markdown 是唯一持久化真源；文件安全、打开、阅读、编辑、搜索、关联、导出和更新构成稳定闭环。

知识库和 AI 在 v1.0 前只使用内部能力接口，不发布第三方插件 SDK，不执行任意 JavaScript，不默认上传用户内容。

## v0.11：治理、契约与可维护性

1. 建立双层 AI 控制面、结构化任务状态、批准队列和仓库外部保护。
2. 完成 #194 的共享 Windows 路径谓词和 TS↔Rust 静态命令契约。
3. 让覆盖率包含 App 与组件，并按用户旅程拆分浏览器测试。
4. 渐进提取设置、工作区和文档会话；保存与 IPC 切片保留 T3 人工确认。
5. 拆分 Rust 命令领域模块，保持命令名和文件行为不变。
6. 收口顶部栏、三类搜索、错误反馈、视觉令牌和截图矩阵。

精确顺序、验收、允许文件和风险见 `ai/plan-v1.json`；本文件不复制当前任务。

## v0.12：体验与性能收敛

- `App.tsx` 降至 3500 行以内；TopBar 使用少量视图模型和动作组。
- CSS 按令牌、框架、工作区、阅读器、编辑器、弹层、响应式和打印拆分。
- 普通控件 32–36px，元信息至少 12px，控件文字 13–14px。
- 修正标签页、命令面板、焦点顺序和读屏语义。
- 测量冷启动、首次可阅读、10MB 文档及 5k/20k 文件工作区。
- 只按测量结果延迟加载导出、图谱、打印和设置；初始 JS gzip 目标不高于 180KB。

## v0.13：知识库能力

- Inbox/Daily 继续写入普通本地 Markdown，不建立私有内容真源。
- 建立属性、标签和图关系索引，支持筛选、定位和重建。
- HTML 先完成清洗、CSP、危险 URL、事件属性、iframe、网络和工作区外资源门禁，再提供只读预览；失败时显示源码。
- Mermaid 按需加载并保留源码回退；JSON Canvas 单独设计规模和文件安全边界。

## v0.14：AI 与扩展接缝

- 建立内部 `DocumentAdapter`、`IndexProvider`、`CommandContribution`、`AiProvider` 与 `ConsentScope`。
- 核心默认不联网；provider 可以是本地服务或用户自行配置的远程服务。
- 发送内容前展示文档/片段、用途和 provider；写回提供来源、差异预览和确认。
- 不加载任意脚本、iframe/WebView 插件，不承诺第三方 ABI。

## v0.15：冻结与兼容

- 冻结 Markdown 保存格式、设置键、IPC 命令和核心快捷键。
- 覆盖损坏设置、异常退出、磁盘满、只读文件、外部删除和大文件降级。
- 验证升级、降级、重装和旧版本数据兼容。
- 关闭所有 P0/P1；P2 必须有明确延期理由。
- `App.tsx` 目标低于 1500 行；Rust 命令入口只保留注册和路由。

## v1.0：发布出口

- Windows x64 安装、卸载、升级、恢复和自动更新完整验证。
- Release、安装包、updater `.sig`、`latest.json`、镜像和 SHA-256 一致。
- 没有 Authenticode 证书时明确披露；不把 updater 签名描述为代码签名。
- 完整前端、Rust、浏览器、真实桌面、安全和恢复矩阵通过。

## 长期边界

- v1.0 前不发布第三方插件 SDK、不内置默认联网 AI、不开放任意脚本插件。
- 不实现账号、云同步、实时协作、移动端、macOS/Linux/Windows ARM 安装包。
- 不实现 DOCX/PDF 原格式回写，不引入常驻后台服务或捆绑本地大模型。
