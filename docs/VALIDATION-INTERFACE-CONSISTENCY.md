# 页面与交互一致性检查（0.15.3）

本轮保留暖白墨绿视觉、页面组成和数据边界，修复真实操作问题。没有人工规模压测，也未连接个人聊天 API 或改写个人记忆库。

## 问题与改动

| 问题                               | 修复                                                                 |
| ---------------------------------- | -------------------------------------------------------------------- |
| 设置、市场与旧 AI 页面同时高亮     | 侧栏选中状态由当前显示页面决定；阅读工具栏的设置也进入同一页面状态   |
| 主题循环按钮与其他设置风格不同     | 改为浅色、深色、跟随系统的明确选择；统一页面标题、返回按钮与焦点样式 |
| 窄窗设置无法直接打开全局导航       | 增加导航入口；抽屉关闭恢复焦点；修复旧文件树绝对定位遮挡底部入口     |
| AI 详情中搜索聚焦隐藏输入          | 窄窗搜索返回列表，草稿仍在“正在编辑”中                               |
| 扩展列表滚动后筛选消失             | 列表单独滚动，筛选固定；AI 与扩展空结果可直接清除条件                |
| API 返回或切换服务直接丢输入       | 页内提供保存后继续、放弃修改、继续编辑；保存失败保留表单             |
| 扩展选中辅助文字与按钮悬停对比不足 | 使用已有语义强调颜色，明确选中和悬停状态                             |

## 验证

- 原实现的五条问题路径均实际失败，分别对应重复导航、主题选择、窄窗 AI 搜索、扩展筛选和 API 未保存切换。
- 新增六条浏览器回归通过，包含草稿保留、键盘焦点、清除筛选、API 保存失败与放弃修改不覆盖已保存内容。
- 前端 311 项测试、16 项脚本测试、架构检查、类型检查与生产构建通过。已有 ModalBehavior 静态规则提示和构建体积提示仍存在，不作为功能通过的依据。
- 浅深色、1440/900/720 宽度共 24 个页面状态，没有横向溢出、页面脚本错误或 Axe WCAG 2A/AA 自动检查违规；最终修复画面已查看。
- 最终完整浏览器、发布包和云端检查结果以本版本发布页为准；不以开发服务器画面替代正式桌面验收。

## 画面来源

`.local/interface-audit/` 是开发服务器的浏览器隔离资料，包含原始问题画面；`final/` 为设置、AI、扩展、API 待保存四个页面，1440、900、720 宽度，浅深色共 24 个状态。使用虚构服务名称，未填写真实密钥、未调用模型。没有修改个人阅读与 AI 数据。画面用于排版和可访问性验证，不声称证明原生 API 或 MCP 网络能力。
