## 1. 结论先行

Moyang Reader 的核心阅读闭环已经可用：Windows x64 本地打开、多个阅读库、文件树、标签页、Markdown/TXT 编辑、Markdown 所见即所得、搜索、双链上下文、书签/批注、PDF/HTML/Word 导出、打印和签名更新链路均有实现或已发布验证。

当前最需要控制的不是继续堆功能，而是把“已实现”“待实机验证”“探索性规划”和“明确不做”分开，并让每个切片只经过一次完整开发、验证、PR 和交接。最新 Issues 查询得到 15 个开放事项，其中 14 个可执行事项、1 个历史跟踪事项；开放 PR 只有 6 个 Dependabot 依赖更新，没有正在进行的产品功能 PR。

本轮整改范围：

- 更新全量任务地图、待办入口、HTML 适配边界和 AI 交接入口；
- 把旧的 Issue 表和历史路线说明标成正确状态；

### 2.1 HTML 适配决定

HTML 值得加入路线，但必须按“安全预览 → 可控编辑 → 分享导出”拆开，不把任意网页运行环境塞进轻量阅读器。

当前事实是：HTML 已经是导出目标，`DocumentKind` 和 Tauri 支持扩展名中还没有 HTML 文档类型；阅读区使用 `dangerouslySetInnerHTML`，因此未来接入 HTML 前必须先建立统一清洗、资源解析和 CSP 边界。

规划任务：

| 任务                    | 目标                                           | 非目标                           | 验收重点                                                           |
| ----------------------- | ---------------------------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| H-01 HTML 安全预览      | 识别 `.html/.htm` 并以只读预览打开             | 不执行脚本、不做浏览器全功能兼容 | `script`、事件属性、危险 URL、外部 iframe 被阻断；错误时仍可看源码 |
| H-02 Markdown 原生 HTML | 允许经过白名单的表格、布局和语义标签           | 不默认放开任意 HTML/JS           | Markdown 真源不丢内容，未知结构回退源码并说明原因                  |
| H-03 HTML 源码编辑      | 在安全预览验证后提供 CodeMirror 源码编辑与保存 | 首版不做 HTML 所见即所得         | 保存、外部修改、撤销、路径和资源提示正确                           |
| H-04 HTML 资源与打印    | 工作区内 CSS/图片相对路径解析，打印和导出一致  | 不自动上传远程资源或整个工作区   | 工作区外资源、网络资源和失败项有明确状态                           |

### 3.1 新的单切片流程

1. **INTAKE**：查一次开放 Issue/PR、用户价值和重复项；没有真实价值就停止。
2. **READY**：写目标、非目标、验收、涉及文件、依赖、风险、回滚、测试级别和版本分类。
3. **DISCOVERY**：只读规则、相关源码、相关测试和一个相似实现，摘要控制在一页内。
4. **DESIGN**：一页以内固定状态边界、异常路径和最小方案；难以逆转才写 ADR。
5. **IMPLEMENT**：只完成一个用户路径；不顺手升级依赖、重构主题或加入下一版本功能。
6. **VERIFY**：按 T0～T3 风险级别运行最小测试；失败只保留首个根因。
7. **CHECKPOINT**：一次原子提交、一次分支推送、一个 PR；记录 SHA、run_id、结论和变化时间。
8. **RELEASE**：仅稳定批次构建 Windows x64 安装包、`.sig`、`latest.json`、GitHub Release 和镜像。
9. **HANDOFF**：更新 Issue、交接、`NEXT.md`、任务指标，然后停止当前任务。

## 5. 完成定义与指标

一个切片只有同时满足以下条件才算完成：代码/文档/测试范围明确；相关 Issue 状态有证据；目标测试通过；必要时有 Windows 桌面路径；一次提交、一个 PR、一个交接摘要；`NEXT.md` 已指向下一项或明确等待；当前聊天已停止。

每个切片在交接中记录：

- 模型请求次数、输入 Token、缓存输入 Token；缓存 Token 不直接等同账单金额，但会占用上下文、增加延迟并触发用量上限；
- 工具调用、失败、重试和网络/权限阻塞次数；
- 构建、单测、浏览器 E2E、桌面 E2E 和发布检查次数；
- 从 INTAKE 到交付的耗时、修改文件数和返工次数；
- 是否只创建一个主要分支和 PR；是否按规则停止并完成交接；
- 磁盘清理前后可再生物大小、保留项和删除项。

有效改进的目标：同一状态不重复查询；一个普通切片不超过一次完整构建；无确定性失败的盲目重试；上下文不塞完整日志；未合并成果不被清理；功能切片交付后不自动开启下一项。
