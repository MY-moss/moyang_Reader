## 删除、重置与合并

- 删除“属性编辑未来开放”的占位文案，用实际属性编辑器替代。
- 移除没有独立发布源的更新按钮和启动检查设置；保留底层更新模块供未来正式发布接入，当前不会把旧版安装包当作新版更新。
- 移除旧仓库发布、镜像、工作树清理脚本以及历史交接入口，新工程保留必要的开发与验证工具。
- 收敛重复的主工具入口；阅读、编辑和修改后的保存直接可见，次要功能归入更多与设置。
- 取消关系图静默截取 25 篇的行为，替换为有总数的筛选与分页。
- 保留纯文本真源、授权和草稿恢复；不采用“先乐观覆盖外部修改再确认”的设想，改为先复核并明确处理冲突。

## 范围取舍

此段以最新确认范围为准：账号、云同步、移动端和其他桌面平台仍不在本轮交付内。回收站、历史恢复与冲突比较已在 0.11 工作台实现。用户于 2026-10-16 明确追加插件市场，0.12 提供按需运行的阅读插件、主题、技能和 MCP 扩展；这替代此前“不做插件”的取舍。DOCX/PDF 保持阅读与来源定位，未声称支持原格式无损编辑。Canvas、Dataview 与完整 Obsidian API 兼容仍是旧愿望清单，不是上一轮确认方案已实现的能力。

自动更新、数字签名和公开下载镜像属于发布基础设施，依赖维护者的证书与账号。此次本地交付不需要这些凭据，也不宣称完成在线发布。已实现能力的最终检查结果见 [验证报告](VALIDATION.md)。

## 属性编辑的实现依据

使用 [YAML 官方文档](https://eemeli.org/yaml/) 的 `parseDocument` 检查语法与映射结构，不把不受信任的 YAML 展开成对象；替换时保留用户输入的属性文本和原正文，不重排未知字段。此项新增 `yaml` 直接依赖，并锁定安装版本。
