# AI 空间实现规范

## 用户场景与验收

- 从书房切换 AI 空间，分别管理知识、长期记忆和技能；返回书房保留未保存草稿。
- 三类记录均支持创建、编辑、检索、来源、标签、项目/Agent 范围；记忆有类型、重要度、置顶和有效期。
- 修订保存历史，并发修改保留草稿、比较原文/最新/本地、合并或另存。合并事务保存新内容并归档来源；归档可恢复、历史可还原；永久删除包含历史及索引。
- 同范围/类型/内容重复写入返回已有记录，默认检索排除归档和过期内容。
- 资料分块、中文/英文检索、来源和片段；可选语义检索；上下文包有限长度，技能先摘要后正文。
- 技能导入/导出 SKILL.md、目录或 ZIP，保留资源，MCP 按需读取资源。资料导入支持 MD/TXT/DOCX/文字 PDF/网页正文，保存独立来源快照，手动检查差异后更新。
- JSON 完整备份包含版本，事务导入不覆盖冲突记录，并报告数量。
- 桌面与独立 MCP 共用 SQLite，WAL、busy_timeout、短事务；没有桌面应用运行也能调用 MCP。
- MCP 提供搜索、读取、保存、归档/恢复、历史、合并、反馈、上下文、技能资源。接入页提供实际路径配置和 Agent 使用约定。

## 架构

crates/ai-core 是无界面的持久化和召回内核；crates/ai-mcp 使用官方 rmcp stdio；Tauri 命令薄封装同一内核；features/ai 是 UI；platform/ai-bridge 是适配。浏览器使用独立本地存储预览，明确说明无法连接本机 MCP。

默认数据在独立应用数据目录 ai-space；MCP 明确传入路径。记录、历史、分块、资源、向量和反馈存同一数据库。普通笔记不导入此数据库。

## 验证计划

1. 内核：持久化、并发版本、回滚、去重、中文召回、分页、过期、关联、合并、历史、备份、资源和删除。
2. MCP 子进程：初始化、发现、三类读写、范围、版本错误、重启、跨进程共享。
3. 语义：单元测试模拟 Ollama 验证向量、错误回退、模型切换和取消；另用真实 qwen3-embedding:0.6b 完成 80 条中文回归，报告样本和负载边界。
4. UI：记录流程、备份/技能往返、切换保留草稿、浅深色、紧凑布局、可访问性。
5. 桌面：真实数据库和 MCP 更新；最终正常桌面可执行文件和 MCP 同目录交付。
