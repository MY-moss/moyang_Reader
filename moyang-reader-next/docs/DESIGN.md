# 工作台界面与交互规范

更新于 2026-10-16。视觉令牌和跨页面规则以根目录 [DESIGN.md](../DESIGN.md) 为准；组件预览、阴影、动效与断点扩展见 [.impeccable/design.json](../.impeccable/design.json)。本文保留工作台的交互与验收说明，避免维护第二份颜色和字体真源。

## 方向与依据

暖白纸面、墨绿强调、本机字体、阅读优先。沿用 Moyang Reader 与 M 标记；工具区采用系统无衬线字体，长正文默认本机衬线字体。界面无需联网字体。Notion / Obsidian 提供统一侧栏、文档标签和属性编辑的工作区思路，内容及文件真源仍遵循本项目的本地使用边界。

已批准方向见 [PRODUCT.md](../PRODUCT.md) 和 [工作台升级检查单](../tasks/workbench-upgrade.md)。本轮由代码主导，没有独立方向契约、QUALITY BAR 卡或批准设计图。本文件记录源码可证实的最终实现，不等同于视觉验收通过报告。

欢迎页以打开文档和添加阅读库为主要入口，辅助说明与快捷键保持次级。导航图标使用共用内联 SVG，随主题文字色变化。

## 文档与编辑

- Markdown 默认直接编辑，保留选区工具条、斜杠菜单及源码模式；TXT、DOCX、PDF 的操作按格式能力提供。
- 单击文件打开临时标签；双击或修改后保留。临时标签采用斜体，两个窗格分别维护标签。
- 停止输入约 1.2 秒后自动保存；中文输入法组词期间暂停。Ctrl+S 可以主动保存，切换内容保留草稿。
- 外部修改和保存冲突提供比较、合并或另存入口；加载失败、保存失败不伪造成功状态。
- 关联内容在侧边预览，来源定位保留上下文；固定双窗格不扩展为任意停靠布局。

## AI 正文与属性

AI 的知识、记忆和技能仍存于独立库，外部内容通过显式导入形成快照。标题是页面首要信息，正文直接使用阅读器的富文本与源码编辑器组件。属性默认折叠，包括共享范围、项目、来源、标签等信息；技能所需的适用场景说明保持显式输入。

AI 预览与编辑共用正文排版规则：字体、字号、标题、列表、引用及链接层级一致。共用编辑器不等于阅读设置已经跨空间同步：阅读器字体由用户偏好覆盖，AI 当前继承根级正文栈，具体值已分别写入根设计令牌。

## 页面式设置

设置在工作台主区域打开，侧栏仍属于工作台。页面没有模态遮罩，分为外观、编辑、导出版式、通用与隐私、数据恢复五类；只显示当前分类，内容区独立滚动。返回工作台和 Escape 关闭后恢复原焦点。

舒适/紧凑密度改变导航与列表的垂直间距，正文字号、阅读缩放和字体仍由外观设置分别控制。设置页中的有效操作即时生效，并按现有存储策略保存在本机。

## 自适应

扩展市场与设置是互斥的全局页面；点击当前空间导航、打开文件或调用空间搜索会退出全局页面，原有文档及 AI 草稿继续保留。AI 侧栏通过组件通知导航，不能依赖 Portal 宿主上的事件冒泡。专注阅读不会隐藏全局页面所需的导航。

市场使用列表与详情的主从结构，发现、已安装、更新是列表筛选；类型与搜索在同层组合。窄窗口用返回列表切换层级。阅读插件采用内容前提供比较；技能升级遇到已经改进的正文时提供副本安装；MCP 配置写入结果明确区别于客户端实际连接状态。错误保留已有内容，启停和回退都有可见反馈。

| 条件           | 布局变化                                           | 保存偏好                                 |
| -------------- | -------------------------------------------------- | ---------------------------------------- |
| 宽窗口         | 全局侧栏、正文、右上下文；侧栏和上下文宽度可拖动。 | 保留用户宽度和开合选择。                 |
| 低于 1100px    | 右上下文默认收起，手动打开为覆盖层。               | 使用临时开合状态，不覆盖保存的右栏状态。 |
| 低于 900px     | 全局侧栏默认收起，手动打开为带遮罩的覆盖导航。     | 不改写保存的侧栏开合状态。               |
| 不超过 820px   | AI 列表与详情分步显示，详情提供返回列表入口。      | 内容和草稿继续保留。                     |
| 不超过 760px   | 双窗格上下排列。                                   | 各窗格标签不合并。                       |
| 720px 窄桌面档 | 压缩 AI 页边距；低于 720px 时设置分类横向换行。    | 放大后恢复对应宽窗口呈现。               |

900px、720px 是桌面窄窗口验收尺寸，不是全部布局断点。当前实现仍在低于 1100px 时收起右上下文。这些规则服务 Windows 桌面缩窗，不构成正式移动端支持承诺。

## 主题、状态与可访问性

浅色、显式深色与跟随系统都使用同一组语义变量。目录文字、占位说明、导航的悬停与选中状态需检查三个主题路径；不能只改变正文背景。按钮和输入保留键盘焦点、禁用状态及可读标签；状态不能仅依靠颜色。

正文与欢迎页不强制播放入场动画；减少动态效果偏好会关闭平滑滚动并缩短过渡。新建、冲突等实际对话框继续使用相应焦点管理，页面式设置不冒充模态对话框。

## 维护与验证边界

`src/styles/index.css` 按基础样式、主题、study、增强、workroom、AI、workbench、extensions、打印的顺序组织入口。更新规则时需检查后续覆盖及组件内联变量，不能仅从旧基础样式推断最终视觉。根设计文件与扩展文件应一起更新，前置令牌保存颜色、字体、圆角、间距与组件原语，扩展保存其余信息。

`artifacts/workbench` 是本轮截图证据目录；最终审阅和测试结果由实际验证记录承担，文档不预先声明通过。验收覆盖宽窗口、900px、720px、主题、临时/保留标签、双窗格、输入法安全保存、页面式设置和 AI 预览/编辑一致性。axe 的严重与致命问题是自动检查范围；屏幕阅读器与 Windows 键盘巡检需要单独记录，不据此推定已经完成。
