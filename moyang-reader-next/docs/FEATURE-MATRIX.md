## 质量验收重点

1. 编辑中切换文档保留逐文档草稿与保存队列；有冲突时提供比较、合并和另存。
2. 文件被外部修改时不静默覆盖本地草稿。
3. 工作区读写不能逃离授权路径，符号链接和新文件路径也受约束。
4. 新工程所有运行时相对导入都留在 `src/` 内，不能引用父工程实现。
5. 欢迎页、阅读页、设置页和必要对话框在浅色/深色和紧凑窗口中可操作，键盘焦点可见。
6. 浏览器测试只证明 Web 侧行为，桌面读写由 Rust/桌面测试分别证明。
