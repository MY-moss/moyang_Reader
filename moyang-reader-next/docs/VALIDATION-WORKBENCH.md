## AI 阶段发现并修正

- 编辑器存在 200ms 延迟通知，快速输入后点击保存会读到旧正文：改为保存/关闭前同步实时编辑内容。
- 表格或分隔线间的根节点光标导致空格被丢弃，随后退格改变首段标题：插入前转到邻近有效文字位置，独立回归通过。
- 活动页和连接页两个布尔状态可能同时为真，导致侧栏选中但页面不切换：改为互斥页面状态，加入往返并保留草稿的测试。
- 语义排名保留真实距离并降低常见中文词噪声；真实用例从 76/80 提升到 80/80，保留中间结果且说明调试集边界。

## 此轮真实测试发现并修正的问题

1. Windows 扩展路径与显示路径不能直接比较：标题已切换而窗格仍显示旧文件。已统一文档身份并补回归测试。
2. 扩展路径中的问号被当作 URL 查询，导致 Markdown 正文索引失败。已区分本地路径和网页 URL。
3. 中文查询对所有单字取并集，带回弱相关段落。改为对查询词及中文双字片段取交集，并保留原文精确命中排序。
4. PDF.js 读取本地 Blob 被原有 CSP 阻止。按 [Tauri CSP 文档](https://v2.tauri.app/security/csp/) 配置本地 Blob、worker 与打包 WASM 所需来源；离线资源仍随应用打包。
5. 删除文件后，文件监听把回收站内部目录重新添加到阅读库。增量刷新和监听均排除内部目录。
6. 旧设置弹窗及重复工具栏的测试需跟随新页面结构更新，保留相同业务断言。
7. 窄窗口的显示导航按钮遮挡 AI 新建入口，已调整为独立布局行。
8. 本机加密 AppData 目录的 JSON 临时文件替换返回 Windows 错误 17，导致设置无法提交、正常关闭被取消。改为 SQLite 事务设置存储，保留旧 JSON 兼容读取；真实关闭/重新启动通过，详见 ADR 0002。
