## 本轮修复

| 场景                              | 修复                                                                                   |
| --------------------------------- | -------------------------------------------------------------------------------------- |
| 长 TXT 深处搜索命中               | 使用字符 Range 滚动到命中位置；显式跳转优先于恢复窗格旧滚动位置                        |
| TXT / Markdown 源码选区收藏或摘录 | 保存源码偏移、结束位置和引用文字；未保存草稿按当前正文指纹定位                         |
| 跨段摘录返回来源                  | 统一空白比较并映射跨节点 Range，重复引用不擅自选择                                     |
| PDF 插页后打开旧摘录              | 比较指纹，存在唯一引用时重新找物理页；无引用或不唯一时提示核对                         |
| 两窗格 PDF 往返激活               | 每个窗格持有独立页码，活动与非活动预览一致                                             |
| 技能资源替换和异步导入            | 打开的预览同步更新；离开或放弃草稿后不提交旧导入；读取期间暂停自动保存和手动保存       |
| 长期积累后的历史查看              | 分页读取版本摘要，展开才读取某一版本正文；资源按路径及版本读取，能识别同路径同长度修改 |
| 周期刷新未变化的 AI 条目          | 通过版本索引返回未变化结果，避免重复传输正文、附件和重算资源指纹                       |
| 多个客户端同时建立语义索引        | 操作系统文件锁协调同一批计算，进程退出自动释放；暂停状态跨进程共享                     |
| 当前范围索引未完成                | 保留完整关键词结果及分页，明确提示状态；该范围完成后恢复语义补充                       |
| AI 完整备份                       | 纳入有用度分数及使用次数，兼容旧备份，导入不覆盖已有记录反馈                           |
| 新包替换连接配置                  | 按安装生效时间及可执行程序来源核对回执，旧连接的成功记录不冒充新连接已就绪             |
| 保存尚未结束时重命名文件          | 等待同一文档的保存及渲染队列结束，再更新文件名和引用，避免旧正文基线覆盖链接修订       |

资源清单、历史分页和按版本读取的契约见 [MCP 指南](MCP-GUIDE.md)。索引未完成时暂用词法检索是本次明确保留的取舍；已有资料的纯语义命中会在该范围索引就绪后恢复，其他项目未完成索引不影响当前项目。
