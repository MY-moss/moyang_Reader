## 依赖检查

使用 npm 官方登记源重新审计；原默认镜像的审计端点未实现，未把该失败当成通过。兼容更新后生产依赖告警由 13 项降至 3 项，high/critical 均为 0。更新包括 Vue 3.5.44、DOMPurify 3.4.17、source-map-js 1.2.2；公式统一使用 KaTeX 0.18.10，避免同时带多份旧版本。

剩余 3 项 moderate 是同一 `mammoth → argparse → sprintf-js` 依赖链。核对当前代码，argparse 仅用于 mammoth 的命令行入口，应用调用的是文档转换库；未找到正文解析调用该参数格式化入口的路径。上游 [sprintf-js 公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) 尚无修复版本，npm 的自动建议是把 mammoth 降到 0.3.29，故不强制降级文档解析器。这一条保留追踪，不表述为零告警。

相关修复依据：[source-map-js](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)、[Vue 服务端渲染](https://github.com/advisories/GHSA-g2v6-rqmx-r4w6)、[KaTeX](https://github.com/advisories/GHSA-238p-pmpm-9mq7)。公式、Markdown 和 DOCX 路径随更新运行整体回归。
