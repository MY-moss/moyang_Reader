# 给阅读留一点时间

这是重构工程附带的示例文档。你可以用它体验目录、排版、查找、编辑和本地链接，内容不来自你的私人资料。

> 文档留在自己的文件夹，打开之后，就从这一段开始。

## 建立一间本地书房

在桌面版中添加 `examples` 文件夹为阅读库。左侧出现文件树，右侧提供当前文档的目录。按 **Ctrl+P** 可以快速找到另一篇文档。

阅读的顺序不必由文件名决定。你可以沿着 [[阅读清单]] 继续，也可以用 Ctrl+F 搜索一个关键词。

## 阅读之后，留下想法

按 **Ctrl+E** 进入编辑，再次按下返回阅读。有修改时，顶部出现保存按钮。只有保存之后，正文才写回这个文件。

- 阅读是默认状态。
- 编辑是明确的选择。
- 本地文件是内容的真源。

## 让格式服务内容

| 资料 | 建议使用方式 |
| --- | --- |
| 文章和笔记 | 阅读目录、查找正文、补充想法 |
| Word 与 PDF | 快速预览，再按需要导出或打开 |
| 一组相关资料 | 添加整个文件夹，并建立文档链接 |

你也可以查看公式：$a^2+b^2=c^2$。

```text
打开 → 阅读 → 思考 → 编辑 → 保存
```

## 继续

试试“更多 → 导出 → 预览打印版式”，或按 Ctrl+Shift+Enter 专注阅读。原文件仍在这个文件夹里。
