# Moyang Reader

个人使用的 Windows 本地阅读与知识工具。阅读空间保留普通文件真源；AI 空间独立存储供 Agent 使用的知识、记忆与技能。无需账户或云端服务。

## 已确认的体验

参考 Notion 与 Obsidian 的侧栏、文档标签和正文编辑，采用暖白、墨绿、系统字体与阅读优先的排版。统一侧栏切换空间，固定双窗格，关联内容侧边预览。默认舒适密度，可选择紧凑。单击临时预览，编辑或双击后保留标签。默认直接编辑，提供选区工具条、斜杠菜单和源码模式。

## 约束

沿用 npm run dev / desktop / build。原工程保留，开发版使用独立身份。中文与离线使用优先，保存、恢复、来源定位必须可靠。AI 内容仅通过显式导入进入独立库。不引入团队权限、账号、OCR、模板、每日笔记、任意窗格停靠或额外模型链。
